=================================================================
====================导                     读====================
=================================================================

  欢迎来到 Vim！Vim 和你平时用的编辑器最大的不同，是它「模式
  化」：同一个键，在不同模式下做的事情完全不一样。

    普通模式（Normal）  按下的键不会变成文字，而是对文字执行
      动作。移动、删除、复制、缩进都在这里做。

    插入模式（Insert）  按下的键会真的变成文字。

  这份教程讲的全是原版 Vim 自带的功能，一个插件都不需要。

  准备好了就按 j 键往下读，直到第一课。

=================================================================
====================1.1  启 动 与 打 开 文 件====================
=================================================================

  vim 文件名        用 Vim 打开一个文件
  vim               打开一个空文件
  :e 文件名         在当前窗口打开另一个文件
  :e!               丢弃当前改动，重新载入这个文件

  Note: 直接敲 vim 就进到空文件，从空文件练手最安全。

=================================================================
===========================1.2  退 出============================
=================================================================

  :q                关闭当前窗口，退回上一个地方
  :q!               强制关闭，把没保存的改动丢掉

  Note: 按 : 之后光标会跳到屏幕最下面那行，就是命令行；敲
        错了按 Esc 就能回普通模式，不会有任何改动。

=================================================================
=========================CHAPTER 1 RECAP=========================
=================================================================

  * vim 文件名 / :e 文件名 打开文件，:e! 丢弃改动重载。

  * :q 关闭当前窗口，:q! 强制关闭并丢掉未保存的改动。

=========================2.1  h  j  k  l=========================
=================================================================

          ^
          k
     <-- h   l -->
          j
          v

  h 在左，l 在右，j 长得像向下的箭头，k 长得像向上的箭头。

  1. 把光标移到下面标有 '-->' 的行。
  2. 用 h j k l 在这几行里随便走一走，找找手感。

  --> Vim is a modal text editor
      Move around with h j k l.

=================================================================
=====================2.2  词 移 动  w  b  e======================
=================================================================

    w        向前跳到下一个词的开头
    b        向后跳到当前词的开头
    e        向前跳到当前词的末尾
    W B E    同上，但只按空白分词（one-of-a-kind 算一个词）

  1. 把光标移到下面标有 '-->' 的行。
  2. 按 3w 看看光标到了哪个词开头，再用 b / e 前后走。

  --> one-of-a-kind text is worth traversing with W

=================================================================
====================2.3  行 内 跳 转 与 翻 屏====================
=================================================================

    0        行首第一个字符
    ^        行首第一个非空白字符
    $        行尾最后一个字符
    gg       文件第一行
    G        文件最后一行
    {N}G     文件第 N 行
    Ctrl-d   向下翻半屏
    Ctrl-u   向上翻半屏
    { }      上一个 / 下一个空行开头的段落
    zz       让光标这一行停在屏幕中间

  1. 按 gg 跳到文件开头，再按 G 跳到最后一行。
  2. 回到中间，用 0 和 $ 在行首行尾之间来回跳。
  3. 按 Ctrl-d 往下翻，翻到尽头再按 Ctrl-u 翻回来。

  Note: 3$ 是倒数第三个字符，^ 在写代码时比 0 更好用。
        屏幕只显示几十行，用跳转代替翻屏会快得多。

=========================CHAPTER 2 RECAP=========================

  * 0 ^ $ 在行内跳转，gg G {N}G 在文件里跳转，Ctrl-d /
    Ctrl-u 翻半屏，{ } 按段落跳。

==========================3.1  i  和  a==========================
=================================================================

  i        在光标这个字符的前面进入插入模式
  a        在光标这个字符的后面进入插入模式（a 是 append）
  Esc      回到普通模式

  1. 把光标移到下面标有 '-->' 的行。
  2. 找一处缺字的地方，按 i，敲进缺的字。
  3. 按 Esc 回到普通模式，重复到整行都对上。
  4. 换个方式：按 a 在光标后面插入，效果和 i 一样。

  --> Th stce misg so.
     This sentence is missing some text.

=================================================================
=========================3.2  I  A  o  O=========================
=================================================================

    I        在行首第一个非空白字符前进入插入模式
    A        在行尾进入插入模式
    o        在下面新开一行，并进入插入模式
    O        在上面新开一行，并进入插入模式

  1. 把光标移到下面标有 '-->' 的行，任意位置。
  2. 按 A，光标会自己跳到行尾，敲上缺的内容。
  3. 按 O，在上面开一行输入注释；按 o，在下面开一行。

  --> The best text editor is

=================================================================
====================3.3  c  s  和 组 合 技 巧====================
=================================================================

    c{动作}    先按 {动作} 选中，再删掉并进入插入模式
    s          删掉光标下这个字符，直接进入插入模式
    C          从光标删到行尾并进入插入模式

  c 是「改变」，它等于「先做 {动作}，再按 i」。

  1. 把光标移到下面标有 '-->' 的行的句号上。
  2. 按 s，句号消失并进入插入模式，敲一个问号。
  3. 按 Esc。试着把光标移到某个词上，按 cw 改掉整个词。

  --> Vim is fun.
     Vim is fun?

  Note: 拿不准自己在哪个模式，就直接按 Esc 回普通模式。

=========================CHAPTER 3 RECAP=========================
=================================================================

  * i 在光标前插入，a 在光标后插入，Esc 回普通模式。

  * I / A 跳到行首第一个非空白字符前 / 行尾，o / O 在下面 /
    上面新开一行。

  * c{动作} 改写选中内容，s 改写光标下这一个字符。

=================================================================
======================4.1  删 除  x  dd  dw======================
=================================================================

    x        删掉光标下的字符
    X        删掉光标前面的字符
    dd       删掉整行
    dw       删到下一个词的开头
    d$ / D   从光标删到行尾

  1. 把光标移到下面标有 '-->' 的行。
  2. 移动到每个多余的字符上，按 x 删掉它。
  3. 删完一行，按 dd 删掉整行。

  --> Thhiss senttencee haass exxtra charracterss.
     This sentence has extra characters.

=================================================================
==================4.2  复 制 与 粘 贴  yy  p  P==================
=================================================================

    yy       复制（yank）整行
    yiw      复制光标所在的词
    p        在光标后面粘贴
    P        在光标前面粘贴

  1. 把光标移到下面标有 '-->' 的行，停在 apple 上。
  2. 按 yiw 把 apple 复制下来。
  3. 把光标移到每个句号后面按 p 粘贴，再试试 yy 复制整行。

  --> I like apple. I like banana. I like pear.
     I like apple. I like apple. I like banana. I like pear.

=================================================================
=======================4.3  撤 销 与 重 做=======================
=================================================================

    u        撤销上一步
    Ctrl-r   重做
    U        撤销对这一行的所有改动

  1. 把光标移到下面标有 '-->' 的行。
  2. 按 x 删掉一个词，然后按 u 把它找回来。
  3. 把整行的错字都改对，改完按 u 全部退回。
  4. 按 Ctrl-r 一次一次把它们 redo 回来。

  --> Undo is the best feature of Vim.

  Note: 括号、换行、粘贴这类成组的改动也算一步，u 一次全撤。

=================================================================
=======================4.4  保 存 与 退 出=======================
=================================================================

  :w           保存
  :w 文件名     另存为另一个名字
  :wq / :x     保存并退出
  :q           关闭当前窗口
  :q!          强制关闭，未保存的改动全部丢掉

  1. 随便打几个字，文件立刻变成「已修改」。
  2. 输入 :w 回车，提示消失，改动写回磁盘。
  3. 再改一点，输入 :q，Vim 会拒绝退出并提醒你。
  4. 这次输入 :wq，改动保存，Vim 关闭这个窗口。

  Note: :q 遇到未保存的改动会停下来，这是保护不是出错。

=========================CHAPTER 4 RECAP=========================
=================================================================

  * x / X 删光标下 / 前的字符，dd 删整行，dw 删到下个词。

  * yy / yiw 复制整行 / 一个词，p 和 P 粘在光标后 / 前；u 撤
    销，Ctrl-r 重做，U 撤销本行改动。

  * :w 保存，:wq 保存并退出，:q! 丢弃改动强制退出。

=====================5.1  找 什 么  /  n  N======================
=================================================================

    /词     向下搜索
    ?词     向上搜索
    n        跳到下一个匹配
    N        跳到上一个匹配
    *        把光标下的词当搜索词，向下找
    #        把光标下的词当搜索词，向上找

  1. 输入 /banana 再回车，光标会跳到第一个 banana。
  2. 用 n 在所有 banana 之间来回跳，用 N 反着跳。
  3. 把光标放到一个单词上，按 * 直接开始找它。

  Note: 搜索可以直接用正则，比如 /^ 找行首缩进。

=================================================================
======================5.2  改 成 什 么  :s=======================
=================================================================

    :s/旧/新/        当前行第一个
    :s/旧/新/g       当前行全部
    :s/旧/新/ic      当前行全部，忽略大小写
    :s/旧/新/gc      当前行全部，逐个问你 y/n
    :%s/旧/新/g      整个文件
    :%s/旧/新/gc     整个文件，逐个问你 y/n
    :%s/旧/新/gn     只数一数有几个，不真的改

  1. 把光标移到下面标有 '-->' 的行。
  2. 输入 :s/banana/orange/g 回车，把这一行的换掉。
  3. 输入 :%s/orange/apple/gc 回车，挨个确认 y 或 n，再用
     :%s/xxx/yyy/gn 数一数有几处。

  --> banana banana banana
     orange orange orange

  Note: 替换前先用 gn 那一版数一遍，确认数量对再动手。

=================================================================
=========================CHAPTER 5 RECAP=========================
=================================================================

  * / 向下找，? 向上找，n / N 下一个 / 上一个。

  * * / # 直接用光标下的词当搜索词。

  * :s/// 换当前行，:%s///g 换整个文件，加 c 逐个确认；加
    i 忽略大小写，加 n 只统计不替换。

========================6.1  v  V  Ctrl-v========================
=================================================================

    v        字符选择模式
    V        行选择模式
    Ctrl-v   块选择模式（按住 Shift 再按 v）

  1. 把光标移到下面标有 '-->' 的行。
  2. 按住 Shift 再按 v，进入块选择模式。
  3. 上下拖动光标，看看方块选中了什么，再按 Esc 退出。

  Note: 可视模式里所有移动都在「扩大选区」，不是移动光标。

=================================================================
====================6.2  选 区 里 能 干 什 么====================
=================================================================

    d    删掉选区
    c    删掉选区并进入插入模式
    y    复制选区
    p    在下面粘一份选区
    >    缩进
    <    反缩进
    :    在选区上执行一条命令
    I    在每一行选区开头进入插入模式
    A    在每一行选区末尾进入插入模式

  1. 按 V 选中下面标有 '-->' 的这一行。
  2. 按 > 缩进整行，注意缩进后选区还在。
  3. 按 I 敲几个字，Esc，这几个字出现在每一行开头。

  -->     a  b  c
     --> d  e  f
     --> g  h  i

  块选择配合 I / A / d，能一次改整齐一片表格：

  1. 按 Ctrl-v，把光标放到第 3 行的第一个字符上。
  2. 用 j l l l 选到第 3 行的某一列。
  3. 按 I，输入 X，Esc，每一行选中的位置都被写上了 X。
  4. 再按一次 Ctrl-v 选同样的区域，按 d 整块删掉。

  --> one two three
     one two three
     one two three

=========================7.1  词  iw  aw=========================
=================================================================

    iw    词内，不含两侧空白
    aw    词外，含后面的空白

  i 和 a 的区别就是「内」和「外」：内不含外围，外含外围。

  1. 把光标移到下面标有 '-->' 的行，停在 any 上。
  2. 按 diw，整个 any 被删掉，空白留下。
  3. 撤销，再按 daw，连后面的空白一起删掉。

  --> This is a word and another word.
     This is a  and another word.

=================================================================
==================7.2  成 对 的 符 号 与 组 合===================
=================================================================

    i" / a"    双引号内 / 外
    i' / a'    单引号内 / 外
    i( / a(    圆括号内 / 外
    i[ / a[    方括号内 / 外
    i{ / a{    花括号内 / 外
    i< / a<    尖括号内 / 外

  1. 把光标移到下面标有 '-->' 的行，停在 hello 上。
  2. 按 ci"，引号里的内容被清空，光标进入插入模式。
  3. 敲上 world，Esc，引号本身留了下来；再试一次 a"。

  --> say("hello", "world")
     say("world", "world")

  文本对象前面还可以接 d、c、y，意思是删、改、复制：

  1. 把光标放到下面标有 '-->' 的行。
  2. 依次试 di(、da(、ci[、ya{。
  3. 试出一个自己的套路，比如 di( ci" yiw，固定下来。

  --> call foo(bar(baz), 42)
     call foo(42), 42)

  Note: 这些文本对象是原版 Vim 自带的，不用装插件。

=======================9.1  寄 存 器 与 宏=======================
=================================================================

  寄存器是 Vim 内部的小抽屉，名字就是一个字符。剪贴板和它
  完全是两回事：Vim 内部的复制默认不进系统剪贴板。

    "ayy     把整行复制进寄存器 a
    "ap     在光标后粘贴寄存器 a 的内容
    "aP     在光标前粘贴寄存器 a 的内容
    :reg    列出所有寄存器和它们的内容
    qa      开始录宏，录到寄存器 a
    q       停止录制
    @a      重放寄存器 a 里的宏
    @@      再重放一次上次那个宏
    3@a     连续重放三次

  1. 输入 :reg，看看抽屉里现在有什么。
  2. 把光标移到下面标有 '-->' 的行，停在 any 上。
  3. 按 "ayy 把整行存进 a 抽屉，再输入 "ap 贴一份出来。
  4. 把光标移到下面第二行，按 qa 开始录。
  5. 用 w 移词、cw 改成 no、j 回下一行，重复第 4 步。
  6. 按 Esc，再按 q 停止录制，回第二行按 @a 重放。

  --> I like any fruit at all.
     go home now
     go home now
     go no now
     go no now

  Note: 重放时 Vim 会先自己回到宏开头的行，所以每行之间
        一样的偏移量，录一次就能一直用。

=================================================================
=========================CHAPTER 9 RECAP=========================
=================================================================

  * 寄存器和剪贴板是两回事，:reg 能看到全部内容。

  * "ayy 存进 a，"ap / "aP 从 a 贴出；qa 开始录，q 停止，
    @a 重放，@@ 重复，3@a 连放三次。

========================10.1  配 置 文 件========================
=================================================================

  Vim 启动时会自动读一个配置文件，叫 .vimrc，放在你的家目
  录下面。在 Vim 里敲 :version 就能看到它实际被读的是哪条
  路径；通常就是 ~/.vimrc。

  1. 输入 :e $MYVIMRC，直接把配置文件打开。
  2. 敲上这几行：

       set number
       set expandtab
       set tabstop=4 shiftwidth=4
       set ignorecase smartcase

  3. 保存这份文件，然后输入 :source $MYVIMRC 让它生效。
  4. 回到教程，再输入 :set number? 看看选项真的改了没。
  5. 试 :set tabstop=2，改完敲 :set tabstop& 让它复位。

    :set 选项?        看这个选项现在是什么值
    :set all          列出所有选项和它们的值
    :source 文件      重新读一遍配置或脚本
    :scriptnames      看看启动时一共加载了哪些脚本

  Note: set tabstop=4 shiftwidth=4 的空格是分隔符，多个选
        项写一行没问题。改坏了 :q! 丢掉就行。

=================================================================
========================CHAPTER 10 RECAP=========================
=================================================================

  * 配置文件是家目录下的 .vimrc，用 :e $MYVIMRC 打开。

  * :source 重新加载，:set 选项? 查看，:set 选项& 复位。

  * 常用几项：number、expandtab、tabstop/shiftwidth、
    ignorecase、smartcase。

  * i a o O 进插入模式，d 删、y 复制、p 粘贴、u 撤销；/ 搜
    索，n 跳下一个，:%s///g 批量替换。

  * v V Ctrl-v 选区，iw aw i" a" 这类文本对象精确动手。

  * :split 管窗口，:tabnew 管标签，q 和 @ 分别是宏。

  * .vimrc 改配置，:source 立刻生效。
