=                             导读                              =
=================================================================

 欢迎来到 Vim！Vim 和你平时用的编辑器最大的不同，是它「模式
 化」：同一个键，在不同模式下做的事情完全不一样。

   普通模式(Normal)  按下的键不会变成文字，而是对文字执行
     动作。移动、删除、复制、缩进都在这里做。

   插入模式(Insert)  按下的键会真的变成文字。

 这份教程讲的全是原版 Vim 自带的功能，一个插件都不需要。

 准备好了就按 j 键往下读，到第一课。

 vim 文件名        用 Vim 打开一个文件
 vim               打开一个空文件
 :e 文件名         在当前窗口打开另一个文件
 :e!               丢弃当前改动，重新载入这个文件

=================================================================

=================================================================

 :q                关闭当前窗口，退回上一个地方
 :q!               强制关闭，把没保存的改动丢掉

 Note: 按 : 之后光标会跳到屏幕最下面那行，就是命令行；敲
       错了按 Esc 就能回普通模式，不会有任何改动。

=                      2.3  行内跳转与翻屏                      =
=================================================================

   0        行首第一个字符
   ^        行首第一个非空白字符
   $        行尾最后一个字符
   gg       文件第一行
   G        文件最后一行
   {N}G     文件第 N 行
   :N       文件第 N 行
   Ctrl-d   向下翻半屏
   Ctrl-u   向上翻半屏
   { }      上一个 / 下一个空行开头的段落
   zz       让光标这一行停在屏幕中间

 1. 按 gg 跳到文件开头，再按 G 跳到最后一行。
 2. 回到中间，用 0 和 $ 在行首行尾之间来回跳。
 3. 按 Ctrl-d 往下翻，翻到尽头再按 Ctrl-u 翻回来。(这里是122行)
 4. 按 123G (G为大写，即 Shift-g) 或使用命令 :123 到这一行。

 Note: 数字加在 $ 前面是「先往下走 N-1 行，再到行尾」，3$ 就
       是先按 2j 再按 $；行内最后一个非空白字符用 g_。

=                     2.4  行内查找字符                         =
=================================================================

   f{字符}     向右找到下一个 {字符}，光标停在它上面
   t{字符}     向右找到下一个 {字符}，光标停在它前面一个字符上
   F{字符}     向左找到上一个 {字符}，光标停在它上面
   T{字符}     向左找到上一个 {字符}，光标停在它后面一个字符上
   ;           重复上一次 f / t / F / T
   ,           反向重复

 f 是「find」，t 是「till」。它们只在**当前行**找，不跨行。

 1. 把光标移到下面标有 '-->' 的行首，按 0。
 2. 按 f) 跳到这一行第一个 ) 上。
 3. 按 t) 跳到 ) 前面一个字符。
 4. 按 ; 重复，, 反向。

 --> call foo(bar, baz) and done)

 配合操作符：

   df)    删到 ) 并包括 )
   dt)    删到 ) 但不包括 )
   cf)    删到 ) 并进入插入模式
   yt)    复制到 ) 前

 1. 把光标放到下面标有 '-->' 的行首。
 2. 按 dt) 删掉括号前的内容，看是不是留下 ) 和后面的。
 3. 按 u 退回，再试 df)，看是不是连 ) 一起删掉。

 --> remove this text) keep this
     ) keep this

 Note: f / t 只找当前行。想跨行找字符，用 /{字符} 搜索。
       大写 F / T 是反方向。

=================================================================

   yy       复制(yank)整行

=                        9.1  寄存器与宏                        =
=================================================================

 寄存器是 Vim 内部的小抽屉，名字就是一个字符。剪贴板和它
 完全是两回事：Vim 内部的复制默认不进系统剪贴板。

   "ayy     把整行复制进寄存器 a
   "ap     在光标后粘贴寄存器 a 的内容
   "aP     在光标前粘贴寄存器 a 的内容
   :reg    列出所有寄存器和它们的内容
   qa      开始录宏，录到寄存器 a
   q       停止录制
   @a      重放寄存器 a 里的宏
   @@ / 3@a   再放一次 / 连续放三次

 1. 输入 :reg，看看这些小抽屉里都装了些什么。
 2. 把光标移到下面标有 '-->' 的行，按 "ayy 存进 a，再按 "ap
    贴一份试试。
 3. 按 u 撤掉贴出来的那一行，把光标移回标有 '-->' 行的行首
    (按 0)。
 4. 按 qa 开始录制，依次按：w、cw、no、Esc、j。
 5. 按 q 停止录制，这时第一行已经变成 go no now。
 6. 把光标移到第二行，按 @a；再按 @@ 改第三行。

 --> go home now
     go home now
     go home now

 全部做完，三行都变成 go no now。

 Note: 录进去的那个 j 让光标每改完一行就往下挪一格，所以连
       着按 @a 就能一行一行改下去，录一次一直能用。

=================================================================
=                        第9章 章节回顾                         =
=================================================================

 * 寄存器和剪贴板是两回事，:reg 能看到全部内容。

 * "ayy 存进 a，"ap / "aP 从 a 贴出；qa 开始录，q 停止，
   @a 重放，@@ 重复，3@a 连放三次。

=                        10.1  配置文件                         =
=================================================================

 Vim 启动时会自动读家目录下的 .vimrc。本教程是用 --clean 打
 开的，所以没有加载任何 vimrc，$MYVIMRC 也是空的；下面用一个
 临时文件练习同样的步骤，不会动到你真正的配置。

 1. 输入 :split ~/.vimrc.practice，新建一个练习配置并在上面
    一半打开。
 2. 敲上这几行：

      set number
      set expandtab
      set tabstop=4 shiftwidth=4
      set ignorecase smartcase

 3. 输入 :w 保存，再输入 :source ~/.vimrc.practice 让它生效。
 4. 按 Ctrl-w j 回到下面的教程窗口，输入 :set number?，看看
    选项真的改了没。
 5. 练完可以 :call delete(expand('~/.vimrc.practice')) 删掉它。

   :set 选项?        看这个选项现在是什么值
   :set all          列出所有选项和它们的值
   :source 文件      重新读一遍配置或脚本

=================================================================
=                        第10章 章节回顾                        =
=================================================================

 * 配置文件通常是家目录下的 .vimrc；--clean 下它不会被加载，
   $MYVIMRC 也是空的，练习时用临时文件代替。

 * :source 重新加载，:set 选项? 查看，:set 选项& 复位。

 * 常用几项：number、expandtab、tabstop/shiftwidth、
   ignorecase、smartcase。

=================================================================
=                      12.1  文本对象进阶                        =
=================================================================

 操作符 d / y / c 后面接「文本对象」，比手动数字符精确得多。

    iw / aw   这个词 / 这个词连同周围空格
    i" / a"   引号里的内容 / 连引号一起
    i( / a(   圆括号里的内容 / 连括号一起
    i{ / a{   花括号里的内容 / 连括号一起
    ip / ap   当前段落 / 当前段落加空行
    it / at   HTML/XML 标签里的内容 / 连标签一起

  1. 把光标放到下面 banana 上，按 diw，单词消失；按 u 恢复。
  2. 把光标移进圆括号里，按 ci(，只改括号里的东西。
  3. 按 yap 复制一整段，再到别处按 p。

  --> foo( banana , 42)
      "hello world"

      a separate paragraph

 Note: i 表示 inside，a 表示 around。文本对象也可以跟在 v 后
       面先选中，比如 vi" 选中引号里的内容。

=================================================================
=                       第12章 章节回顾                          =
=================================================================

 * iw/aw、i"/a"、i(/a(、ip/ap 是最高频的文本对象。
 * d/c/y + 文本对象，比用 h/l 一个个挪精确得多。
 * i 是「里面」，a 是「连同包裹符号」。

=================================================================
=                       13.1  宏：录制与重放                     =
=================================================================

 宏就是把一串按键录进寄存器，然后一键重放。

    qa        开始录制到 a 寄存器
    q         停止录制
    @a        重放 a 寄存器里的宏
    @@        重放上一次用过的宏
    10@a      重放 10 次
    qA        往 a 寄存器末尾追加录制

  1. 把光标放到下面第一行。
  2. 依次按 qa I- <Esc> j q，录一个「行首加 - 并下移一行」的宏。
  3. 按 @a，第二行也加上 -；按 @@，第三行也加上。
  4. 按 10@a 一次处理剩下几行。

  --> apple
      banana
      cherry
      date

 Note: 录宏时用 j/k/w/0/$ 这类相对移动，别写死行号。录错了
       用 :let @a=' 清空，或者 :reg a 看看录了什么。

=================================================================
=                       第13章 章节回顾                          =
=================================================================

 * q<字母> 录制、q 结束、@<字母> 重放、@@ 重复上一次。
 * N@a 批量重放，qA 追加录制。
 * 宏存在寄存器里，:reg 能查看。

=================================================================
=                       14.1  寄存器进阶                         =
=================================================================

    ""        无名寄存器：普通 y / d / p 默认使用
    "0        最近一次 yank，不会被删除操作覆盖
    "1~"9     最近九次删除，1 是最新
    "a~"z     26 个命名寄存器
    "+        系统剪贴板（需要 +clipboard）
    "*        X11 主选区
    :reg      查看所有寄存器

  1. 按 yy 复制一行，再按 dd 删另一行。
  2. 按 "0p，贴回来的是刚才 y 的那行，而不是刚删的那行。
  3. 选中一段按 "ay，再到别处按 "ap。

 Note: 大写寄存器名表示追加，比如 "Ay 会把内容接着存进 a。
       在 Wayland / 无剪贴板支持的环境里，"+ 可能不可用。

=================================================================
=                       第14章 章节回顾                          =
=================================================================

 * "0 保存最近 yank，删除不会覆盖它。
 * "a~"z 是命名寄存器，大写名表示追加。
 * :reg 查看全部寄存器内容。

=================================================================
=                       15.1  窗口进阶                           =
=================================================================

    :split / :vsplit      上下 / 左右分屏
    :new / :vnew          新空窗口 / 右侧新空窗口
    C-w w                 依次跳到下一个窗口
    C-w h/j/k/l           跳到左/下/上/右窗口
    C-w c / C-w o         关闭当前 / 只留当前
    C-w H/J/K/L           把窗口挪到左/下/上/右
    C-w =                 所有窗口等大
    :resize +5            当前窗口高度加 5 行

  1. 输入 :vsplit 左右分屏。
  2. 按 C-w l 到右边窗口，按 C-w = 均分宽度。
  3. 按 C-w o 关掉其它窗口。

 Note: 每个窗口可以独立设置 wrap、number 之类的窗口局部选项，
       用 setlocal 而不是 set。

=================================================================
=                       第15章 章节回顾                          =
=================================================================

 * :split / :vsplit 分屏，C-w 前缀管跳转、关闭、移动和调整大小。
 * C-w o 只留当前，C-w = 均分。
 * 窗口局部选项用 setlocal。

=================================================================
=                      16.1  标签页                              =
=================================================================

    :tabnew / :tabedit 文件   新建标签 / 在新标签打开文件
    gt 或 :tabnext            下一个标签
    gT 或 :tabprevious        上一个标签
    :tabclose                 关闭当前标签
    :tabonly                  只留当前标签
    :tabmove +1 / -1          标签右移 / 左移
    :tabs                     列出标签

  1. 输入 :tabnew 新建标签，再按 gt / gT 来回切。
  2. 输入 :tabmove +1，看顶部标签顺序变化。
  3. 输入 :tabs 看列表，最后 :tabonly 只留当前。

 Note: 标签页是「窗口的容器」，不是文件和标签一一绑定。关闭
       标签不会自动保存文件。

=================================================================
=                       第16章 章节回顾                          =
=================================================================

 * gt / gT 切标签，:tabnew / :tabclose / :tabonly 管理标签。
 * :tabmove 调整顺序，:tabs 列出全部。
 * 标签页里可以再分窗口。

=================================================================
=                      17.1  替换与 :global                      =
=================================================================

    :%s/旧/新/g       全文替换（每行所有匹配）
    :%s/旧/新/gc      逐个确认：y 是、n 否、a 全部、q 退出
    :s/旧/新/         只处理当前行
    :'<,'>s/旧/新/g   只处理选区
    :g/模式/命令      对匹配的行执行命令
    :v/模式/命令      对不匹配的行执行命令

  1. 输入 :%s/banana/apple/g，把下面的 banana 全换掉。
  2. 输入 :g/^$/d，删掉所有空行；按 u 撤销。
  3. 输入 :v/^#/d，只保留以 # 开头的行。

  --> banana and banana
      # keep me
      another banana

 Note: 替换里的 & 表示「刚才匹配到的内容」，:%s/banana/&&/g
       会把每个 banana 变成 bananabanana。

=================================================================
=                       第17章 章节回顾                          =
=================================================================

 * :%s/旧/新/g 全文替换，加 c 逐个确认。
 * :g/模式/命令 和 :v/模式/命令 按条件批量处理行。
 * :'<,'> 表示刚才的可视选区范围。

=================================================================
=                       18.1  正则表达式入门                     =
=================================================================

    .       任意一个字符        *       前一个东西重复 0 次以上
    \+      前一个东西重复 1 次以上    \?      0 或 1 次
    ^ / $   行首 / 行尾          \< \>   单词边界
    [abc]   字符集合            [^abc]  排除集合
    \d      数字                \s      空白
    \v      very magic：括号、+、| 不用再加反斜杠
    \c / \C 忽略 / 区分大小写

  1. 输入 /\v(foo|bar) 回车，foo 和 bar 都会高亮。
  2. 输入 /^\s*\d\+ 找「行首空白后跟数字」的行。
  3. 输入 /\chello 忽略大小写搜 hello。

  --> foo one
      bar two
      123 numbers

 Note: 搜索时打开 incsearch 可以边打边看结果；hlsearch 会让
       所有匹配保持高亮，:nohlsearch 临时取消。

=================================================================
=                       第18章 章节回顾                          =
=================================================================

 * . * \+ \? ^ $ \< \> [] \d \s 是最常用的一批原子。
 * \v 让正则少写反斜杠，\c / \C 控制大小写。
 * incsearch + hlsearch 让搜索结果即时可见。

=================================================================
=                      19.1  缩进与格式化                        =
=================================================================

    ==        按当前缩进规则整理一行
    =G        从当前行整理到文件末尾
    gg=G      整个文件基础缩进
    > / <     右移 / 左移一级
    gqap      重排当前段落（按 textwidth 折行）
    :set expandtab tabstop=4 shiftwidth=4   常用的四空格设置

  1. 把下面代码缩进打乱，按 gg=G 看它恢复。
  2. 输入 :set textwidth=40，把光标放到一段长文本上按 gqap。

    def f(a,b):
    x=a+b
        return x

 Note: 真正复杂的格式化要用外部工具（gofmt / black / prettier），
       Vim 自带的 = 只依据缩进规则，不会重排代码结构。

=================================================================
=                       第19章 章节回顾                          =
=================================================================

 * == / =G / gg=G 做基础缩进，上下箭头 > < 调整一级。
 * gq 按 textwidth 重排文本。
 * 外部格式化工具比 = 更懂语言结构。

=================================================================
=                        20.1  折叠                              =
=================================================================

    zf        创建折叠        zo        打开一处
    zc        关闭一处        za        开关切换
    zM        全部折起        zR        全部展开
    zj / zk   跳到下 / 上一个折叠
    :set foldmethod=indent   按缩进自动折叠

  1. 输入 :set foldmethod=indent。
  2. 打开一个有缩进的文件，按 zM 全折。
  3. 按 zj 跳到下一处，按 zo 展开，最后 zR 全部展开。

 Note: foldmethod 还可以是 manual / syntax / marker。用 manual
       时 zf 自己创建折叠，indent 时由缩进自动生成。

=================================================================
=                       第20章 章节回顾                          =
=================================================================

 * zf / zo / zc / za 管单个折叠，zM / zR 管全部。
 * zj / zk 在折叠间跳。
 * foldmethod 决定折叠从哪里来。

=================================================================
=                      21.1  多文件与缓冲区                      =
=================================================================

    :e 文件       打开新文件（原文件留在缓冲区列表）
    :ls           列出缓冲区
    :b 编号/名字  切到指定缓冲区
    :bn / :bp     下一个 / 上一个缓冲区
    :bd           删除当前缓冲区
    :args *.txt   把一类文件放进参数列表
    :argdo 命令   对参数列表每个文件执行命令

  1. 输入 :ls 看看当前缓冲区。
  2. 用 :e 打开另一个文件，再用 :b 加文件名片段切回来。
  3. 输入 :args *.txt 后，用 :argdo echo % 看看列表内容。

 Note: 默认切走未保存的缓冲区会被拦住；设置 hidden 后可以不
       保存就切走，但要记得之后统一 :wall 保存。

=================================================================
=                       第21章 章节回顾                          =
=================================================================

 * :e 打开文件，:ls 看缓冲区，:b / :bn / :bp 切换，:bd 删除。
 * :args + :argdo 批量处理一组文件。
 * hidden 允许切走未保存的缓冲区。

=================================================================
=                      22.1  终端与外部命令                      =
=================================================================

    :!命令      执行一条 shell 命令，比如 :!ls
    !!命令      把当前行交给命令处理，并用输出替换它
    :r !命令    把命令输出插到光标下面
    :term       开一个内置终端窗口
    C-\ C-n     从终端模式回到普通模式
    :close      关掉终端窗口

  1. 输入 :!echo hello，看完结果按回车回到 Vim。
  2. 输入 :r !date，把当前日期插进文件。
  3. 输入 :term 开终端，敲几行命令，再按 C-\ C-n 退出终端模式，
     输入 :close 关掉窗口。

 Note: --clean 模式下不会加载插件，但 :term、:! 这些是 Vim
       自带功能，依然可用。终端窗口本质也是一个缓冲区。

=================================================================
=                       第22章 章节回顾                          =
=================================================================

 * :! 跑外部命令，!! 过滤当前行，:r ! 插入命令输出。
 * :term 开内置终端，C-\ C-n 回普通模式。
 * 终端窗口用 :close 关闭。

=                           23.1  完                            =
=================================================================

 教程到这里就结束了。你已经知道：

 * Vim 是模式化的：普通模式做动作，插入模式写字，Esc 是
   回到普通模式的万能钥匙。

 * hjkl 走路，w b e 按词跳，0 ^ $ 定位行内，gg G 定位文件。

 * i a o O 进插入模式，d 删、y 复制、p 粘贴、u 撤销；/ 搜
   索，n 跳下一个，:%s///g 批量替换。

 * v V Ctrl-v 选区，iw aw i" a" 这类文本对象精确动手。

 * :split 管窗口，:tabnew 管标签，q 录制、@ 重放宏。

 * .vimrc 改配置，:source 立刻生效。
 * 文本对象让 d/c/y 精确操作一个词、一对括号或一整段。
 * q 录宏、@ 重放；寄存器 "0、命名寄存器 "a 各有用处。
 * :split / :tabnew 管窗口和标签；:%s / :g 做批量修改。
 * fold 折叠、:args 多文件、:term 终端，都是 Vim 自带能力。
