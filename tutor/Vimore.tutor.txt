=================================================================
=                             导读                              =
=================================================================

 这份教程讲 Vimore 在原版 Vim 之上加的东西：Leader 菜单、系
 统剪贴板、括号操作、终端、折叠、Git、格式化等等。原版 Vim
 怎么用不在这里讲，hjkl、i、dd、v、:%s/// 这些基础请先在
 vim.tutor.txt 里过一遍(最好用 vim --clean vim.tutor.txt 打
 开基础教程，因为 Vimore 修改了一些原版的操作)。

=================================================================
=                    1.1  Leader 就是空格键                     =
=================================================================

 按下 <Space> 一次(只按一下就松开)，屏幕右下角会立刻弹出
 一个小菜单，列出目前所有可用的键。

 1. 把光标放到任意一行上，按一下空格，菜单马上出现。
 2. 按 Esc 关掉它；再按一下空格也能关。菜单 3 秒不动会自己
    收起。

 菜单长这样，叶子在上，子菜单在下，中间空一行：

 /  Toggle comment
 ?  Open tutorial
 P  System paste before
 Q  Quit all
 W  Save all
 f  Format code
 p  System paste after
 q  Quit
 r  Show registers
 y  Yank to clipboard

 b  <Brackets>
 c  <Maintain>
 g  <Git>
 h  <Display>
 l  <LSP>
 s  <Sort / clean>
 t  <Window>
 w  <Write>
 z  <View>

 Note: 带尖括号的是子菜单，进得去；其余的按下去就执行。菜单
       出现后按 Esc、再按空格、或按菜单里没有的键都会关掉。
       按到菜单里没有的键时，那个键关掉菜单后还会正常生效，
       不会吞掉 j / k。

=================================================================
=                       1.2  子菜单与退出                       =
=================================================================

 在菜单里再按一个键，就能进子菜单或者执行命令。

 1. 按空格调出菜单，按 b，标题变成 Leader b - Brackets，再按 d
    进到第三层，标题是「Delete surrounding symbols only」。
 2. 按 Esc，整个菜单一次全关(Esc 不是退一层)。

 第二层(按 b 之后)长这样，三个都是子菜单：

 a  <Wrap visual selection>
 c  <Change surrounding symbols>
 d  <Delete surrounding symbols only>

 再按 d，第三层列出五种括号(键 + 用途)：

 " Double quote  ' Single quote   ( Parentheses   [ Square brackets   { Braces

 Note: 标题里写着当前路径，看到 Leader b 就知道自己进了一层。
       按到菜单里没有的键，菜单也会直接关掉，这个键随后照常
       生效。

=================================================================
=                        第1章 章节回顾                         =
=================================================================

 * 单独按一下空格，屏幕右下角立刻弹出 which-key 风格的菜单。
 * 带 <名字> 的是子菜单，标题里显示当前路径。
 * Esc、再按空格、或按菜单里没有的键，整个菜单直接关掉；菜单
   里没有的键关掉菜单后还会正常生效。
 * SPC y / p / P 是菜单里的叶子项，按完立即执行。

=================================================================
=                      2.1  保存退出与查看                      =
=================================================================

   SPC w    保存当前文件
   SPC w s  清理整个文件的行尾空格
   SPC w c  光标位置的信息(行、字、字节)
   SPC W    保存所有窗口里的文件
   SPC Q    退出所有窗口
   C-s      保存(普通模式和插入模式都认)
   SPC h h  关掉搜索高亮
   SPC h x  用十六进制方式看当前文件
   SPC h X  退出十六进制显示

 1. 随便改几行，按空格调出菜单，按 w 进"Write"，再按 w 保
    存；在插入模式里直接按 C-s 也一样能存，而且会留在插入
    模式，可以接着写。
 2. 输入 /菜单 回车找几个，按空格 h h，搜索高亮就没了。(记得
    回来)
 3. 按空格 h x 把文件变成十六进制看原始字节，改完按空格 h X
    换回来。

 Note: 存完会提示一下，2 秒后自动清掉。十六进制模式看的是文
       件原始字节，编辑器乱码或想看清不可见字符时很管用。

=================================================================
=                        第2章 章节回顾                         =
=================================================================

 * SPC w 保存，SPC w s 清行尾空格，SPC w c 看光标位置信息。
 * SPC W Save all，SPC Q Quit all，C-s 在普通/插入模式都能存。
 * SPC h h Clear search highlight，SPC h x / X 进 / 出十六进制。

=================================================================
=                        3.1  系统剪切板                        =
=================================================================

   SPC y  把当前行复制到系统剪贴板
   SPC p  在光标后粘系统剪贴板
   SPC P  在光标前粘系统剪贴板
   C-x    可视模式里把整个选区剪进系统剪贴板
   F2     普通/插入模式里开关粘贴模式

 1. 把光标移到下面标有 '-->' 的行，停在 banana 上。
 2. 按空格 y 就完事了，菜单不会出现，这一行已经在剪贴板里。
 3. 切到别的程序粘一下，粘的应该是这一行；回 Vim 按空格 p
    把它贴回来。

 --> I like banana and banana.

 再看 C-x，它是剪切(连删带拷)，不是单纯的复制：

 1. 把光标移到下面标有 '-->' 的 half 上，按 v，按三下 l 选
    中它，按 C-x：half 消失并进了剪贴板，这一行变成下面第
    二行的样子(中间留下两个空格)。

 --> whole half whole
     whole  whole

 Note: 原版 Vim 的 yy 只在内部复制；Vimore 特意关掉了剪贴板
       自动同步，所以 SPC y / p / P 才是真剪贴板。

=================================================================
=                        第3章 章节回顾                         =
=================================================================

 * SPC y 复制到系统剪贴板，SPC p / SPC P 粘回来。
 * 可视模式里 SPC y / p / P 作用于选区，C-x 把选区剪进剪贴
   板。
 * F2 在普通和插入模式都能开关粘贴模式，粘外部代码时很好用。

=================================================================
=                         4.1  快速注释                         =
=================================================================

 SPC / 在普通模式里注释 / 取消注释光标这一行；在可视模式里选
 中几行再按 SPC /，就对整块做同样的事。

 1. 把光标移到下面第一行，按空格 /，行前面多了注释符。
 2. 再按一次空格 /，符号没了。
 3. 按 V 选中下面三行，按空格 /，整块一起注释；再按一次还
    原。

 --> # python
     x = 1
     y = 2

 注释符是按文件类型自动挑的：

   #   python sh bash zsh yaml yml ruby perl
   --  lua sql
   //  c cpp java javascript typescript go rust
              csharp php json scss
   "         vim vimrc
   <!-- -->  html markdown
   /* */     css
   %         tex

 Note: 认不出来的文件类型就退回 #，也就是普通行注释。选区
       模式下只有每一行都注释了才整块去掉，否则整块加上，
       所以反复按一定还原。

=================================================================
=                        第4章 章节回顾                         =
=================================================================

 * SPC / 注释或取消注释当前行，可视模式选中几行再按同
   一个键。
 * 注释符按文件类型自动选，按一次加，按两次还原。
 * 支持 # -- // " <!-- --> /* */ % 这些风格。

=================================================================
=                    5.1  智能补全与智能退格                    =
=================================================================

 在插入模式里敲 ( [ { 会自动补全另一半，敲 ) ] } > 时如果
 光标正好停在对应的那一半上，会直接跳过它。

 1. 插入模式，输入 foo(，屏幕上自动变成 foo(|)。
 2. 输入 bar，这时按 )，光标会跳过右边那个现成的 )，不会多
    打一个。若想删掉整对括号，先把 bar 退格删光，让光标回到
    (|) 中间，再按一次退格。

 " 也一样：光标后已经有同款引号就直接跳过去；光标后紧跟别的
 字符就只打这一个；在空处则数前面的引号，偶数次自动补一对，
 奇数次只打这一个。

 1. 插入模式，输入 x = ""，光标自动停在两个引号中间。
 2. 直接按退格，"" 一起消失了。
 3. 再输入一遍 x = "hello"，把 hello 一个个删掉，光标停在空
    的 "" 中间按退格，效果一样。

 Note: 退格是成对的，空的 () [] {} "" 在中间按一次退格就整个
       消失。自动补全左半边的只有 ( [ { 和 "(vim 文件里除
       外)，< 只在 HTML / XML 里补全。

 在空的 () [] {} 中间按回车，会拆成三行、光标停在中间那行；在
 数组 / 对象这类容器的**末尾**（右括号前）按回车，会把右括号挪到
 下一行，内容单独占一行，例如：

   local xs = [1, 2, 3]   →   local xs = [
                                 1, 2, 3
                             ]

 两种拆分都留在插入模式，不会经过普通模式，所以有 LSP 时不会突然
 闪一下诊断标签。

=================================================================
=                      5.2  删括号与加括号                      =
=================================================================

 SPC b d 之后选括号类型，就把光标所在的那一对括号连里面的东西
 一起删掉；SPC b a 是反过来，给选区外面套一对括号。

   SPC b d ( [ { " '  删掉光标所在的那对括号和内容
   SPC b a ( [ { " '  给可视选区外面套一对括号

 1. 把光标放进下面标有 '-->' 行的双引号里，按空格 b d "，
    只删掉两个引号，内容保留：

 --> foo("bar")
     foo(bar)

 2. 按 u 退回，再按空格 b c '，把当前包裹符号换成单引号：

 --> foo("bar")
     foo('bar')

 Note: 连内容一起删用 Vim 自带的 da( / da" / da{ 等；b d 只
       动符号，b c 换成别的符号。

 3. 按 V 选中整行，按空格 b a (，整行被套上括号，第二行是加
    完的样子。

 --> print(sum(a, b))
     (print(sum(a, b)))

 Note: 选区跨行时，左括号加在第一行选中处，右括号加在最后
       一行选中处。

=================================================================
=                        第5章 章节回顾                         =
=================================================================

 * 插入模式里 ( [ { " 自动配对(< 只在 HTML 里)，) ] } > 会
   自动跳过。
 * 退格是成对的，空的 () [] {} "" 一次退格全消失。
 * SPC b d ( [ { " ' 删括号和内容，SPC b a 给选区加括号。

=================================================================
=                        6.1  终端与运行                        =
=================================================================

   SPC t t  在底部开一个终端
   SPC t v  在右边开一个终端
   SPC t k  有终端就关掉，没有就重新开一个
   SPC t r  在最新的那个终端里跑当前文件
   F5       直接跑当前文件
   F6       调试当前文件

 1. 按空格 t t，屏幕下方三分之一变成终端，敲 ls 回车。
 2. 按 C-\ C-n 回到普通模式，再按空格 t k 把终端关掉。
 3. 新建一个 .py 文件写几行 print，按 SPC t r / F5 看输出。

   print("hello")
   print("vimor")

 Note: 终端里按 C-\ C-n 回普通模式，C-S-c 复制、C-S-v
       粘到系统剪贴板。C-S-h/j/k/l 切换窗口。

 Note: SPC t r 先存盘再跑，没终端就现开一个，命令按类型选：
       Python 走 python3，Go 走 go run，C / C++ 编译再跑，
       JS 走 node，Java 走 java，Shell 走 bash，Lua 走 lua，
       Rust 走 cargo run。F5 和 SPC t r 是同一套逻辑；F6 调试
       支持 Python(pdb)、C / C++(gdb) 和 Go(dlv)。

=================================================================
=                        第6章 章节回顾                         =
=================================================================

 * SPC t t 开底部终端，SPC t v 开右侧终端，SPC t k 开 / 关。
 * 终端里 C-\ C-n 回普通模式，C-S-c / C-S-v 走系统剪贴板。
   C-S-h/j/k/l 切换窗口。
 * SPC t r 存盘后在最新终端里跑，F5 直接跑，F6 调试。

=================================================================
=                    7.1  文件浏览器与标签页                    =
=================================================================

   F3           在当前窗口开文件浏览器
   F4           垂直分屏开文件浏览器
   SPC t f      和 F3 一样
   SPC t F      和 F4 一样
   SPC t n      New tab
   SPC t e      新标签打开当前文件
   SPC t c      关闭当前标签
   SPC t o / l  只留当前标签 / 列出所有标签
   SPC t u / d  Open alternate file in tab / 在新标签里打开所在目录
   SPC t M / N  标签左移 / 右移
   Alt 左       / 右  上一个 / 下一个标签页

 1. 按 F3，出现一个列表，目录树在前，文件在后。
 2. 把光标移到某个文件名上按回车，就在当前窗口打开了。
 3. 按 F4 试一次，浏览器和文件左右分屏；再按空格 t e，在
    新标签里打开当前文件。

 Note: 浏览器里的顺手键：回车打开，o 水平分屏开，v 垂直分屏
       开，t 新标签开，P 回到上个窗口，p 预览，i 换列表样
       式，Ctrl-l 刷新，% 是在当前目录新建文件；关掉浏览器
       用 :q。

 Note: 不带 Leader 的顺手记一下：C-h C-j C-k C-l 切窗口，
       Alt-左右切标签。原版的 C-t 是 tag 跳转、C-w 是窗口
       前缀，这里没有改掉它们；新建标签用 SPC t n。

=================================================================
=                        第7章 章节回顾                         =
=================================================================

 * F3 / F4 开文件浏览器，SPC t f / F 同上。
 * SPC t n 新标签，SPC t e 新标签开当前文件，SPC t c 关。
 * SPC t u 在新标签打开上一个文件，SPC t o 只留当前，M / N 移
   标签，l 列出。

=                           8.1  折叠                           =
=================================================================

   SPC z z  把所有能折的都折起来
   SPC z a  在光标这行折 / 展开切换
   SPC z Z  Unfold all

 1. 打开一个缩进过的文件，比如下面这段。
 2. 把光标放在第二行按空格 z z，整段折成一行；再按空格 z a
    展开那一行，按空格 z Z 全部摊平。

   func main() {
       if ok {
           run()
       }
       done()
   }

 Note: 折叠按缩进算，文件得先有缩进；折起来那行末尾显示
       + 开头的内容 ... N lines。

=================================================================
=                        第8章 章节回顾                         =
=================================================================

 * SPC z z Fold all，SPC z a 在光标处切换，SPC z Z 展开。
 * 折叠按缩进判断，折起来那行会告诉你藏了几行。

   SPC s s  排序
   SPC s u  排序并去掉重复
   SPC s n  按数字大小排序
   SPC s d  删掉所有空行

 1. 用 V 选中下面四行，按空格 s，字母排好了。
 2. 再按空格 s u，重复的那行没了。
 3. 用 V 选中下面三个数字，按空格 s n，10 会跑到 9 后面。

 --> banana
     apple
     cherry
     apple

 --> 10
     9

=================================================================

 * SPC s s 排序，SPC s u 排序去重，SPC s n 数字序。
 * SPC s d 删掉文件里所有空行，普通模式排整个文件。
 * 可视模式里 SPC s / su / sn 只作用于选区。

=                           10.1  Git                           =
=================================================================

   SPC g s  git status
   SPC g d  git diff
   SPC g l  git log --oneline --graph
   SPC g a  git add 当前文件
   SPC g c  git commit，会让你写一句说明
   SPC g p  git push
   SPC g P  git pull

 1. 在一个 git 仓库里打开一个文件。
 2. 按空格 g d，看看你改了哪些行。
 3. 按空格 g a 暂存，按空格 g c 写说明提交；再按 g l 看提

 Note: 输出直接刷在屏幕上，看完按回车或 Esc 关掉那半屏。
       SPC g a 只暂存当前这一个文件，不是 git add .，提交
       前记得先按 SPC g s 看一眼状态。

=================================================================

 * SPC g s / d / l 分别是 status、diff、log。
 * SPC g a 暂存当前文件，SPC g c 提交，p 推送，P 拉取。

=================================================================
=                    11.1  配置维护与格式化                     =
=================================================================

   SPC c e  打开 Vimore 的配置文件
   SPC c v  重新加载 Vimore 的配置
   SPC c c  跑一次代码检查，和 F8 一样
   SPC c h  Run :checkhealth vimore，检查环境
   SPC c k  查看快捷键总览
   SPC f    自动格式化当前文件
   F9       基础格式化，就是 gg=G
   F10      自动格式化，和 SPC f 一样
   F7       切换自动换行，并报一下当前 wrap

 1. 按空格 c e 打开配置，在顶部把 author 和 email 改成你
    自己的，保存。
 2. 回别的窗口按空格 c v，改动立刻生效。
 3. 把下面这段缩进打乱的代码敲进新文件，按 F9 排好。

   def f(a,b):
   x=a+b
       return x

   def f(a, b):
       x = a + b
       return x

 Note: SPC f 会先看系统里有没有对应的工具：Python 用 black
       或 ruff / autopep8，Go 用 gofmt，JS / TS 用 prettier
       或 eslint，C / C++ 用 clang-format，Lua 用 stylua，
       Rust 用 rustfmt，Shell 用 shfmt，Markdown 用 prettier
       或 mdformat；都没有就退回 F9 那种基础缩进。格式化和
       检查都是异步的，不会卡住编辑器。

 Note: SPC c c 会按文件类型找检查工具：Python 用 ruff /
       pylint / flake8，JS / TS 用 eslint，Go 用 go vet，
       Rust 用 cargo check，Lua 用 luac，Shell 用 shellcheck，
       C / C++ 用语法检查，JSON 用 jq，YAML 用 yamllint 等。
       保存时行尾空格会被自动清掉，Markdown / diff / gitcommit
       例外，因为行尾空格在这些格式里有意义。

=                        第11章 章节回顾                        =
=================================================================

 * SPC c e 打开配置，改完 SPC c v 重新加载，记得先改顶部
   的 author 和 email，新建文件的头会用。
 * SPC f / F10 自动格式化，F9 基础缩进，SPC c c / F8 检查；
   SPC c h 自检，SPC c k 看快捷键总览。
 * SPC w s 清行尾空格，保存时会自动清，Markdown / diff /
   gitcommit 除外。

=================================================================
=                     12.1  缩进与缩进宽度                      =
=================================================================

 缩进用标准 Vim 操作符：< 和 > 后面要跟一个动作或再按一次
 自己。

   >>  当前行缩进一级
   <<  当前行反缩进一级
   >j  当前行和下一行一起缩进
   =   按缩进规则自动排版(gg=G 是全文)

 1. 把光标移到下面第三行(缩进多的 done())，按 <<，它和第
    二行对齐了。
 2. 按 u 退回原样，再按 >> 缩进一级，来回试几次。
 3. 按 V 选中三行，按 >；Vimore 会保持选区，可以连续按 >。

 --> if ok
     run()
         done()

 缩进宽度按文件类型定：

   4 格  python sh c cpp java rust javascript typescript
           html css json markdown lua
   2 格  yaml
   Tab   go(gofmt 风格，noexpandtab)

 1. 新建一个 .py 文件按 Tab，得到 4 个空格；再新建一个 .go 按
    Tab，得到一个制表符。用 :set shiftwidth? 和 :set expandtab?
    随时确认。

=================================================================
=                        第12章 章节回顾                        =
=================================================================

 * 普通模式用 >> / << 缩进 / 反缩进当前行，>j 管两行。
 * 可视模式里选中几行按 > / <，会一起缩进，还保持选中。
 * 宽度按文件类型：多数语言 4 格，YAML 2 格，Go 用制表符；
   F9 是 gg=G 基础排版。

=                    13.1  行号状态栏和光标                     =
=================================================================

 普通模式显示相对行号，插入模式显示绝对行号，切换是自动
 的，你什么都不用按。

 1. 把光标停在下面标着 (2) 的那行，看左边那列的数字。
 2. 按 i 进插入模式，数字立刻变成真的行号；Esc 出去又变
    回相对的。

   (1) 第一行显示 1
   (2) 光标在第二行，这里是 2
   (3) 下面那行显示 1

 状态栏被换成了这样，左边是模式，右边一堆信息：

   [-] init.lua  [lua] [unix] [utf-8] [128,9] [42%] 21:30

 左边那个方括号是模式指示器，每种模式一个颜色：

   [-] 普通             [I] 插入   [v] 可视   [V] 行可视
   [B] 块可视 [R] 替换  [C] 命令行 [T] 终端

 右边依次是文件类型、格式、编码、行列、百分比和时间；改过
 没保存时文件名后面跟一个 +。标签栏也是定制的，名字太长会
 截短成一个 …，当前标签高亮。

 Note: 光标也跟着模式换：插入是竖线，普通和可视是方块，替换
       是下划线。行尾空格显示成淡灰色的 ·（不用背景块，也不
       像报错），第 120 列有一条
       淡竖线提醒你该换行了。

=================================================================
=                        第13章 章节回顾                        =
=================================================================

 * 普通模式相对行号，插入模式绝对行号，自动切。
 * 状态栏左边是模式指示器，右边是类型、格式、编码、行列、
   百分比、时间。
 * 标签栏会截短过长的名字，光标形状跟着模式变。

=                      14.1  文件头与补全                       =
=================================================================

 新建 .py .go .sh .bash .c .cc .cpp .h .hpp .java .js .ts .rs
 .lua 这些文件时，Vimore 会自动帮你填好开头。

 1. 输入 :e hello.py 新建一个空文件，文件头当时就填好了：shebang
    后面是三引号注释，按 @file / @author / @email / @date / @brief
    分点列清楚；Python 3 默认 UTF-8，不再写编码行。
 2. 再 :e hello.c，C 文件只有注释头，不会强行塞 include 和
    main；:e hello.go 会按目录名推导 package，只有 main 包
    才顺手生成 func main。
 3. 保存再编辑，文件头保持原样；换别的后缀再试，头是各写各
    的。

 输命令和文件名时也都有补全：

   Tab        在候选里往下选一个
   Shift-Tab  往上选一个
   Enter      选中当前这个候选
   Ctrl-n     不用 Tab 也能往下翻候选

 LSP 附加后，插入模式还会自动弹补全；也可以随时按
 Ctrl-x Ctrl-o 手动触发 omnifunc。

 1. 敲 :sp，下面会列出一列候选，按 Tab 选到 :split。
 2. 敲 :e 加一个文件名的前几个字母，Tab 补出完整路径。

 Note: 作者和邮箱取配置顶部的 author 和 email，第一次用记得
       先去 SPC c e 改掉；留空就不写这两行。

=                  15.1  不用 Leader 的顺手键                   =
=================================================================

 Leader 菜单管的是「低频但功能多」的命令；高频动作还是裸键最快。

    C-s        保存；插入模式里按完继续打字，不会弹回普通模式
    C-h/j/k/l  在窗口之间移动（左/下/上/右）
    Alt-左/右  上一个/下一个标签页
    C-t        Vim 默认行为：弹出标签栈，不是新建标签
    C-x        可视模式里把选区剪进系统剪贴板
    F1         帮助
    F2         普通/插入模式切粘贴模式
    F3/F4      File explorer（当前窗口 / 垂直分屏）
    F5         在终端里运行当前文件
    F6         在终端里调试当前文件
    F7         切换当前窗口的自动换行，并显示 wrap 状态
    F8         异步代码检查，问题放进 quickfix
    F9         基础缩进 gg=G
    F10        异步调用外部格式化工具

  1. 随便打开一个文件，插入几个字后按 C-s，注意光标还在插入
    模式，接着打字即可。
  2. 按 :split 分出两个窗口，按 C-j / C-k 在两个窗口间跳。
  3. 按 C-t 看看标签栈行为；新建标签请用 SPC t n。

 Note: C-w 仍然是窗口命令前缀，C-w c 关当前窗口，C-w o 只留
       当前窗口。Vimore 没有霸占它。

=                        第15章 章节回顾                        =
=================================================================

 * 高频动作走裸键：C-s 保存、C-h/j/k/l 切窗口、Alt-左右切标签。
 * C-t 与 j/k 保持 Vim 默认，F1~F10 各司其职。
 * F7 只影响当前窗口，且手动切过之后不再被文件类型规则覆盖。

=                   17.1  IDE 体验：可选 LSP                    =


Vim 版本身不带 LSP；可选装 yegappan/lsp 插件来获得跳转、补全和诊断。

    gd / gD    跳定义 / 声明
    gr / gi    查找引用 / 跳实现
    K          悬停文档
    <C-k>      签名帮助
    SPC l      打开 LSP 子菜单（诊断、符号、格式化等）
    <C-Space>  不要用来触发补全（输入法会占用）；用 <C-x><C-o>

  1. 打开一个 Python 或 C 文件，把光标放到函数名上按 gd。
  2. 按 K 看文档；按 gr 看所有引用。
  3. 输入 :VioreHealth 或 :messages，看插件和工具是否就绪。

 Vim 版没有 inlay hints / Code Lens / 语义 token；这些是 NeoVim 专属。

 装了可选 LSP 后，gd / gr / K / SPC l 等键位和 NeoVim 保持一致。

 Note: 没有装对应语言服务器时，这些功能自动跳过，不报错。
       可选 LSP 片段在 ~/.vim/plugin/vimore-plugins.vim。

=                  18.1  语义高亮、配色与颜色                   =

主题写死在 Vimore.vimrc 第 3 节，没有 colors/ 目录；单文件就是完全体。
真彩终端用 hex，其它终端自动折算成 256 色。

    紫色  关键字 / 语句
    蓝色  函数名、C 指针 *（单独高亮）
    橙色  运算符（= < + 等），包括声明初始化里的 =
    绿色  字符串
    黄色  类型、数字
    淡灰  注释、行尾空格的 ·
    红色  错误 / 删除

 1. 打开一个 C 文件，观察 void swap(int *x, int *y)：
    参数名是正文色，* 是蓝色，= 是橙色。
 2. 输入 :echo g:colors_name 和 :highlight Operator 看颜色。
 3. Vim 用传统语法高亮，没有 LSP 语义 token 覆盖注释的问题。

 Note: 颜色只负责「区分语义」，不表示严重程度；错误才用红色。
       运算符统一橙色，指针单独蓝色，都是为了颜色一致性。

=================================================================

 * 运算符橙、指针蓝、关键字紫、字符串绿、类型黄。
 * Lua 的语义 token 特殊处理是 NeoVim 专属。

=               21.1  综合练习：整理一个排序程序                =

把这一章当成结业练习：打开一个空 C 文件，从头写出并整理下面这段。

    #include <stdio.h>

    void swap(int *x, int *y) {
      int tmp = *x;
      *x = *y;
      *y = tmp;
    }

 1. 用 SPC b d 只删掉一对括号，再用 SPC b c 换成别的符号，最后 u 撤销。
 2. 用 da( 连内容一起删一对括号，体会它和 SPC b d 的区别。
 3. 按 F10，确认 clang-format 把 2 格改成 4 格，= 是橙色，* 是蓝色。
 4. 用 gd / gr / K 体验 LSP；用 ]d / [d 在诊断间跳。
 5. 输入 :g/^$/d 删掉所有空行；:%s/int /unsigned int /gc 逐个确认替换。
 6. 用 SPC F 找文件，SPC t t 开终端运行程序，SPC g s 看 git 状态。

 Note: 卡住时按 SPC c k 看快捷键总览，:checkhealth vimore 看环境。

 教程到这里就结束了。你已经知道：

 * 空格是 Leader，单独按一下立刻弹菜单，Esc / 再按空格 / 按错
   键都会关掉；菜单里没有的键关掉菜单后照常生效。

 * SPC z 折叠，SPC s 排序，SPC g 是 Git，SPC c 管配置、

   Code Lens / 语义 token。

 * 仓库根目录还有一个纯 Vimscript 小游戏 VimMaze：输入 :VimMaze
