=================================================================
=                             导读                              =
=================================================================

 这份教程讲 Vimore 在原版 Vim 之上加的东西：Leader 菜单、系
 统剪贴板、括号操作、终端、折叠、Git、格式化等等。原版 Vim
 怎么用不在这里讲，hjkl、i、dd、v、:%s/// 这些基础请先在
 vim.tutor.txt 里过一遍(最好用 vim --clean vim.tutor.txt 打
 开基础教程，因为 Vimore 修改了一些原版的操作)。

=================================================================
=                    1.1  Leader 就是空格键                     =
=================================================================

 按下 <Space> 一次(只按一下就松开)，屏幕右下角会弹出一个小
 菜单，列出目前所有可用的键。

 1. 把光标放到任意一行上，按一下空格，菜单会停在屏幕上。
 2. 按 Esc 关掉它。

 菜单长这样，叶子在上，子菜单在下，中间空一行：

 /      注释/取消注释
 P      从系统剪切板粘贴(前)
 Q      全部退出
 W      全部保存
 f      格式化代码
 p      从系统剪切板粘贴
 q      退出
 r      查看寄存器
 y      复制到系统剪切板

 b      <括号>
 c      <维护>
 g      <Git>
 h      <显示>
 s      <整理>
 t      <窗口>
 w      <写入>
 z      <视图>

 Note: 带尖括号的是子菜单，进得去；其余的按下去就执行。按空
       格之后有 300 毫秒判断你是接着按 y / p / P 还是要开菜
       单；菜单开起来就会一直等待，按 Esc / 不存在的子项 才
       会关掉。

=================================================================
=                       1.2  子菜单与退出                       =
=================================================================

 在菜单里再按一个键，就能进子菜单或者执行命令。

 1. 按空格调出菜单，按 b，标题变成 Leader b - 括号，再按 d
    进到第三层，标题是「删除指定括号对及其内容」。
 2. 按 Esc，整个菜单一次全关(Esc 不是退一层)。

 第二层(按 b 之后)长这样，两个都是子菜单：

 a      <在可视选区外添加指定括号>
 d      <删除指定括号对及其内容>

 再按 d，第三层列出五种括号(键 + 用途)：

 " 双引号   ' 单引号   ( 圆括号   [ 方括号   { 花括号

 Note: 标题里写着当前路径，看到 Leader b 就知道自己进了一层。
       按到菜单里没有的键，菜单也会直接关掉。

=================================================================
=                        第1章 章节回顾                         =
=================================================================

 * 单独按一下空格，屏幕右下角弹出 which-key 风格的菜单。
 * 带 <名字> 的是子菜单，标题里显示当前路径。
 * Esc 或按菜单里没有的键，整个菜单直接关掉；顶层按 q 执
   行退出。
 * SPC y / p / P 有更长的映射，会直接执行，菜单不出现。

=================================================================
=                      2.1  保存退出与查看                      =
=================================================================

   SPC w     保存当前文件
   SPC w s   清理整个文件的行尾空格
   SPC w c   光标位置的信息(行、字、字节)
   SPC W     保存所有窗口里的文件
   SPC Q     退出所有窗口
   C-s       保存(普通模式和插入模式都认)
   SPC h h   关掉搜索高亮
   SPC h x   用十六进制方式看当前文件
   SPC h X   退出十六进制显示

 1. 随便改几行，按空格调出菜单，按 w 进「写入」，再按 w 保
    存；在插入模式里直接按 C-s 也一样能存，还会自动回普通
    模式。
 2. 输入 /菜单 回车找几个，按空格 h h，搜索高亮就没了。(记得
    回来)
 3. 按空格 h x 把文件变成十六进制看原始字节，改完按空格 h X
    换回来。

 Note: 存完会提示一下，2 秒后自动清掉。十六进制模式看的是文
       件原始字节，编辑器乱码或想看清不可见字符时很管用。

=================================================================
=                        第2章 章节回顾                         =
=================================================================

 * SPC w 保存，SPC w s 清行尾空格，SPC w c 看光标位置信息。
 * SPC W 全部保存，SPC Q 全部退出，C-s 在哪儿都能存。
 * SPC h h 取消搜索高亮，SPC h x / X 进 / 出十六进制。

=================================================================
=                        3.1  系统剪切板                        =
=================================================================

   SPC y     把当前行复制到系统剪贴板
   SPC p     在光标后粘系统剪贴板
   SPC P     在光标前粘系统剪贴板
   C-x       可视模式里把整个选区剪进系统剪贴板
   F2        插入模式里开关粘贴模式

 1. 把光标移到下面标有 '-->' 的行，停在 banana 上。
 2. 按空格 y 就完事了，菜单不会出现，这一行已经在剪贴板里。
 3. 切到别的程序粘一下，粘的应该是这一行；回 Vim 按空格 p
    把它贴回来。

 --> I like banana and banana.

 再看 C-x，它是剪切(连删带拷)，不是单纯的复制：

 1. 把光标移到下面标有 '-->' 的 half 上，按 v，按三下 l 选
    中它，按 C-x：half 消失并进了剪贴板，这一行变成下面第
    二行的样子(中间留下两个空格)。

 --> whole half whole
     whole  whole

 Note: 原版 Vim 的 yy 只在内部复制；Vimore 特意关掉了剪贴板
       自动同步，所以 SPC y / p / P 才是真剪贴板。

=================================================================
=                        第3章 章节回顾                         =
=================================================================

 * SPC y 复制到系统剪贴板，SPC p / SPC P 粘回来。
 * 可视模式里 SPC y / p / P 作用于选区，C-x 把选区剪进剪贴
   板。
 * F2 是插入模式的粘贴开关，粘外部代码时很好用。

=================================================================
=                         4.1  快速注释                         =
=================================================================

 SPC / 在普通模式里注释 / 取消注释光标这一行；在可视模式里选
 中几行再按 SPC /，就对整块做同样的事。

 1. 把光标移到下面第一行，按空格 /，行前面多了注释符。
 2. 再按一次空格 /，符号没了。
 3. 按 V 选中下面三行，按空格 /，整块一起注释；再按一次还
    原。

 --> # python
     x = 1
     y = 2

 注释符是按文件类型自动挑的：

   #          python sh bash zsh yaml yml ruby perl
   --         lua sql
   //         c cpp java javascript typescript go rust
              csharp php json scss
   "          vim vimrc
   <!-- -->   html markdown
   /* */      css
   %          tex

 Note: 认不出来的文件类型就退回 #，也就是普通行注释。选区
       模式下先看第一行是不是已经注释了，是就整块去掉，不
       是就整块加上，所以反复按一定还原。

=================================================================
=                        第4章 章节回顾                         =
=================================================================

 * SPC / 注释或取消注释当前行，可视模式选中几行再按同
   一个键。
 * 注释符按文件类型自动选，按一次加，按两次还原。
 * 支持 # -- // " <!-- --> /* */ % 这些风格。

=================================================================
=                    5.1  智能补全与智能退格                    =
=================================================================

 在插入模式里敲 ( [ { 会自动补全另一半，敲 ) ] } > 时如果
 光标正好停在对应的那一半上，会直接跳过它。

 1. 插入模式，输入 foo(，屏幕上自动变成 foo(|)。
 2. 输入 bar，这时按 )，光标会跳过右边那个现成的 )，不会多
    打一个；按退格则 () 一起消失。

 " 也一样：光标后已经有同款引号就直接跳过去；光标后紧跟别的
 字符就只打这一个；在空处则数前面的引号，偶数次自动补一对，
 奇数次只打这一个。

 1. 插入模式，输入 x = ""，光标自动停在两个引号中间。
 2. 直接按退格，"" 一起消失了。
 3. 再输入一遍 x = "hello"，把 hello 一个个删掉，光标停在空
    的 "" 中间按退格，效果一样。

 Note: 退格是成对的，空的 () [] {} "" 在中间按一次退格就整个
       消失。自动补全左半边的只有 ( [ { 和 "(vim 文件里除
       外)，< 只在 HTML / XML 里补全。

=================================================================
=                      5.2  删括号与加括号                      =
=================================================================

 SPC b d 之后选括号类型，就把光标所在的那一对括号连里面的东西
 一起删掉；SPC b a 是反过来，给选区外面套一对括号。

   SPC b d ( [ { " '    删掉光标所在的那对括号和内容
   SPC b a ( [ { " '    给可视选区外面套一对括号

 1. 把光标放进下面标有 '-->' 行的 (baz) 里，停在 b 和 a 之
    间，按空格 b d (，第二行是删完的样子。

 --> call foo(bar(baz), 42)
     call foo(bar, 42)

 2. 按 u 退回去，把光标放进 { key: val } 里，按空格 b d {：

 --> if ok { key: val }
     if ok

 3. 按 u 退回去，按 V 选中整行，按空格 b a (，整行被套上括
    号，第二行是加完的样子。

 --> print(sum(a, b))
     (print(sum(a, b)))

 Note: 光标不在括号里面会提示「光标不在 () 内」。选区跨行时，
       左括号加在第一行头上，右括号加在最后一行尾巴上。

=================================================================
=                        第5章 章节回顾                         =
=================================================================

 * 插入模式里 ( [ " 自动配对(< 只在 HTML 里)，) ] } > 会
   自动跳过。
 * 退格是成对的，空的 () [] {} "" 一次退格全消失。
 * SPC b d ( [ { " ' 删括号和内容，SPC b a 给选区加括号。

=================================================================
=                        6.1  终端与运行                        =
=================================================================

   SPC t t   在底部开一个终端
   SPC t v   在右边开一个终端
   SPC t k   有终端就关掉，没有就重新开一个
   SPC t r   在最新的那个终端里跑当前文件
   F5        直接跑当前文件
   F6        调试当前文件

 1. 按空格 t t，屏幕下方三分之一变成终端，敲 ls 回车。
 2. 按 Esc 回到普通模式，再按空格 t k 把终端关掉。
 3. 新建一个 .py 文件写几行 print，按 SPC t r / F5 看输出。

   print("hello")
   print("vimor")

 Note: 终端里按 C-\ C-n 回普通模式，C-S-c 复制、C-S-v
       粘到系统剪贴板。

 Note: SPC t r 先存盘再跑，没终端就现开一个，命令按类型选：
       Python 走 python3，Go 走 go run，C 是 gcc 编译再跑，
       JS 走 node，Shell 走 bash，Rust 走 cargo run。F5 直接
       在屏幕里跑，类型比它多 Java 和 HTML(firefox 打开)
       但没有 Rust；F6 调试走 pdb、gdb 或 dlv。

=================================================================
=                        第6章 章节回顾                         =
=================================================================

 * SPC t t 开底部终端，SPC t v 开右侧终端，SPC t k 开 / 关。
 * 终端里 Esc 回普通模式，C-S-c / C-S-v 走系统剪贴板。
 * SPC t r 存盘后在最新终端里跑，F5 直接跑，F6 调试。

=================================================================
=                    7.1  文件浏览器与标签页                    =
=================================================================

   F3        在当前窗口开文件浏览器
   F4        垂直分屏开文件浏览器
   SPC t f   和 F3 一样
   SPC t F   和 F4 一样
   SPC t n   新建标签
   SPC t e   新标签打开当前文件
   SPC t c   关闭当前标签
   SPC t o / l   只留当前标签 / 列出所有标签
   SPC t u / d   找回刚关的标签 / 在新标签里打开所在目录
   SPC t M / N   标签左移 / 右移
   Alt 左  / 右  上一个 / 下一个标签页

 1. 按 F3，出现一个列表，目录树在前，文件在后。
 2. 把光标移到某个文件名上按回车，就在当前窗口打开了。
 3. 按 F4 试一次，浏览器和文件左右分屏；再按空格 t e，在
    新标签里打开当前文件。

 Note: 浏览器里的顺手键：回车打开，o 水平分屏开，v 垂直分屏
       开，t 新标签开，P 回到上个窗口，p 预览，i 换列表样
       式，Ctrl-l 刷新，% 是在当前目录新建文件；关掉浏览器
       用 :q。

 Note: 不带 Leader 的顺手记一下：C-h C-j C-k C-l 切窗口，
       C-t 新标签，Alt-左右切标签。C-w 在这里是关标签页，
       不是关窗口，别按错。

=================================================================
=                        第7章 章节回顾                         =
=================================================================

 * F3 / F4 开文件浏览器，SPC t f / F 同上。
 * SPC t n 新标签，SPC t e 新标签开当前文件，SPC t c 关。
 * SPC t u 找回，SPC t o 只留当前，M / N 移标签，l 列出。

=                           8.1  折叠                           =
=================================================================

   SPC z z   把所有能折的都折起来
   SPC z a   在光标这行折 / 展开切换
   SPC z Z   全部展开

 1. 打开一个缩进过的文件，比如下面这段。
 2. 把光标放在第二行按空格 z z，整段折成一行；再按空格 z a
    展开那一行，按空格 z Z 全部摊平。

   func main() {
       if ok {
           run()
       }
       done()
   }

 Note: 折叠按缩进算，文件得先有缩进；折起来那行末尾显示
       + 开头的内容 ... N lines。

=================================================================
=                        第8章 章节回顾                         =
=================================================================

 * SPC z z 全部折叠，SPC z a 在光标处切换，SPC z Z 展开。
 * 折叠按缩进判断，折起来那行会告诉你藏了几行。

   SPC s s   排序
   SPC s u   排序并去掉重复
   SPC s n   按数字大小排序
   SPC s d   删掉所有空行

 1. 用 V 选中下面四行，按空格 s，字母排好了。
 2. 再按空格 s u，重复的那行没了。
 3. 用 V 选中下面三个数字，按空格 s n，10 会跑到 9 后面。

=                           10.1  Git                           =
=================================================================

   SPC g s   git status
   SPC g d   git diff
   SPC g l   git log --oneline --graph
   SPC g a   git add 当前文件
   SPC g c   git commit，会让你写一句说明
   SPC g p   git push
   SPC g P   git pull

 1. 在一个 git 仓库里打开一个文件。
 2. 按空格 g d，看看你改了哪些行。
 3. 按空格 g a 暂存，按空格 g c 写说明提交；再按 g l 看提

 Note: 输出直接刷在屏幕上，看完按回车或 Esc 关掉那半屏。
       SPC g a 只暂存当前这一个文件，不是 git add .，提交
       前记得先按 SPC g s 看一眼状态。

=================================================================

 * SPC g s / d / l 分别是 status、diff、log。
 * SPC g a 暂存当前文件，SPC g c 提交，p 推送，P 拉取。

=                    11.1  配置维护与格式化                     =
=================================================================

   SPC c e   打开 Vimore 的配置文件
   SPC c v   重新加载 Vimore 的配置
   SPC c c   跑一次代码检查，和 F8 一样
   SPC f     自动格式化当前文件
   F9        基础格式化，就是 gg=G
   F10       自动格式化，和 SPC f 一样
   F7        切换自动换行，并报一下当前 wrap

 1. 按空格 c e 打开配置，在顶部把 author 和 email 改成你
    自己的，保存。
 2. 回别的窗口按空格 c v，改动立刻生效。
 3. 把下面这段缩进打乱的代码敲进新文件，按 F9 排好。

   def f(a,b):
   x=a+b
       return x

   def f(a, b):
       x = a + b
       return x

 Note: SPC f 会先看系统里有没有对应的工具：Python 用 black
       或 autopep8，Go 用 gofmt，JS / TS 用 prettier 或
       eslint，C / C++ 用 clang-format，Java 用 astyle，都
       没有就退回 F9 那种基础缩进。

 Note: SPC c c 走的是 Python 的 pylint / flake8 和
       JavaScript 的 eslint，其他类型会直接告诉你不支持。
       保存时行尾空格会被自动清掉，Markdown 例外，因为行尾
       两个空格在 Markdown 里是换行的意思。

=================================================================
=                        第11章 章节回顾                        =
=================================================================

 * SPC c e 打开配置，改完 SPC c v 重新加载，记得先改顶部
   的 author 和 email，新建文件的头会用。
 * SPC f / F10 自动格式化，F9 基础缩进，SPC c c / F8 检查。
 * SPC w s 清行尾空格，保存时会自动清，Markdown 除外。

=================================================================
=                     12.1  缩进与缩进宽度                      =
=================================================================

 在普通模式里，< 和 > 单独按一下就能把当前行缩进一级，不
 用带上数字；可视模式里选中几行再按，就一起缩进。

 1. 把光标移到下面第三行(缩进多的 done())，按 <，它和第
    二行对齐了。
 2. 按 u 退回原样，再按 > 缩进一级，来回试几次。

 --> if ok
     run()
         done()

 缩进宽度是按文件类型定的：

   4 格    python sh go c cpp java rust
   2 格    javascript typescript html css json yaml markdown

 1. 新建一个 .py 文件敲 4 个空格，再建一个 .js 的敲同样 4
    个空格，看它怎么排；用 :set shiftwidth? 随时确认。

=================================================================
=                        第12章 章节回顾                        =
=================================================================

 * 普通模式单按 < / > 就缩进 / 反缩进当前行，不带数字。
 * 可视模式里选中几行再按，会一起缩进，还保持选中。
 * 宽度按文件类型：Python、Go、C 4 格，JS、HTML 2 格。

=================================================================
=                    13.1  行号状态栏和光标                     =
=================================================================

 普通模式显示相对行号，插入模式显示绝对行号，切换是自动
 的，你什么都不用按。

 1. 把光标停在下面第 3 行，看左边那列的数字。
 2. 按 i 进插入模式，数字立刻变成真的行号；Esc 出去又变
    回相对的。

   (1) 第一行显示 1
   (2) 光标在第二行，这里是 2
   (3) 下面那行显示 1

 状态栏被换成了这样，左边是模式，右边一堆信息：

   [-] Vimore.vimrc  [vim] [unix] [utf-8] [128,9] [42%] 21:30

 左边那个方括号是模式指示器，每种模式一个颜色：

   [-] 普通   [I] 插入   [v] 可视   [V] 行可视
   [B] 块可视 [R] 替换   [C] 命令行 [T] 终端

 右边依次是文件类型、格式、编码、行列、百分比和时间；改过
 没保存时文件名后面跟一个 +。标签栏也是定制的，名字太长会
 截短成一个 …，当前标签高亮。

 Note: 光标也跟着模式换：插入是闪烁竖线，普通是方块，可视
       是不闪的方块。行尾空格会变成灰色一小段，第 120 列有
       一条淡竖线提醒你该换行了。

=                        第13章 章节回顾                        =
=================================================================

 * 普通模式相对行号，插入模式绝对行号，自动切。
 * 状态栏左边是模式指示器，右边是类型、格式、编码、行列、
   百分比、时间。
 * 标签栏会截短过长的名字，光标形状跟着模式变。

=                      14.1  文件头与补全                       =
=================================================================

 新建 .py .go .sh .c .cpp .java .js 这几种文件时，Vimore 会自
 动帮你填好开头。

 1. 输入 :e hello.py 新建一个空文件，文件头当时就填好了，看
    看是不是有 shebang、编码行，和一块带作者、邮箱、日期的
    三引号注释；再 :e hello.c 看有没有 include 和 main。
 2. 保存再编辑，文件头保持原样；换别的后缀再试，头是各写各
    的。

 输命令和文件名时也都有补全：

   Tab        在候选里往下选一个
   Shift-Tab  往上选一个
   Enter      选中当前这个候选
   Ctrl-n     不用 Tab 也能往下翻候选

 1. 敲 :sp，下面会列出一列候选，按 Tab 选到 :split。
 2. 敲 :e 加一个文件名的前几个字母，Tab 补出完整路径。

 Note: 作者和邮箱取配置顶部的 author 和 email，第一次用记得
       先去 SPC c e 改掉。

 教程到这里就结束了。你已经知道：

 * 空格是 Leader，单独按一下弹菜单，Esc 或按错键就关掉，顶层
   q 退出。
 * SPC w / W / Q 管保存退出，C-s 在哪儿都能存；SPC y / p /
   P 走系统剪贴板，普通 yy 只在 Vim 内部。
 * SPC / 快速注释，注释符按文件类型自动挑。
 * SPC b d 删括号和内容，SPC b a 给选区加括号；插入模式自
   动补全括号引号，退格成对删除。
 * SPC t t / v / k / r 管终端，F5 跑、F6 调试，F3 / F4 浏览。
 * SPC z 折叠，SPC s 排序，SPC g 是 Git，SPC c 管配置。
 * < 和 > 单按就缩进，行号、状态栏、光标形状都跟着模式变。
