=================================================================
=                             导读                              =
=================================================================

 欢迎来到 Vim！Vim 和你平时用的编辑器最大的不同，是它「模式
 化」：同一个键，在不同模式下做的事情完全不一样。

   普通模式（Normal）  按下的键不会变成文字，而是对文字执行
     动作。移动、删除、复制、缩进都在这里做。

   插入模式（Insert）  按下的键会真的变成文字。

 这份教程讲的全是原版 Vim 自带的功能，一个插件都不需要。

 准备好了就按 j 键往下读，直到第一课。

=================================================================
=                      1.1  启动与打开文件                      =
=================================================================

 vim 文件名        用 Vim 打开一个文件
 vim               打开一个空文件
 :e 文件名         在当前窗口打开另一个文件
 :e!               丢弃当前改动，重新载入这个文件

=================================================================
=                           1.2  退出                           =
=================================================================

 :q                关闭当前窗口，退回上一个地方
 :q!               强制关闭，把没保存的改动丢掉

 Note: 按 : 之后光标会跳到屏幕最下面那行，就是命令行；敲
       错了按 Esc 就能回普通模式，不会有任何改动。

=================================================================

 * vim 文件名 / :e 文件名 打开文件，:e! 丢弃改动重载。

 * :q 关闭当前窗口，:q! 强制关闭并丢掉未保存的改动。

=================================================================

         ^
         k
    <-- h  l -->
          j
          v

 h 向左，l 向右，j 向下，k 向上。

 1. 把光标移到下面标有 '-->' 的行。
 2. 用 h j k l 在这几行里随便走一走，找找手感。

 --> Vim is a modal text editor
     Move around with h j k l.

=                       2.2  词移动 w b e                       =
=================================================================

   w        向前跳到下一个词的开头
   b        向后跳到当前词的开头
   e        向前跳到当前词的末尾
   W B E    同上，但只按空白分词（one-of-a-kind 算一个词）

 1. 把光标移到下面标有 '-->' 的行。
 2. 按 3w 看看光标到了哪个词开头，再用 b / e 前后走。

 --> one-of-a-kind text is worth traversing with W

=================================================================
=                      2.3  行内跳转与翻屏                      =
=================================================================

   0        行首第一个字符
   ^        行首第一个非空白字符
   $        行尾最后一个字符
   gg       文件第一行
   G        文件最后一行
   {N}G     文件第 N 行
   Ctrl-d   向下翻半屏
   Ctrl-u   向上翻半屏
   { }      上一个 / 下一个空行开头的段落
   zz       让光标这一行停在屏幕中间

 1. 按 gg 跳到文件开头，再按 G 跳到最后一行。
 2. 回到中间，用 0 和 $ 在行首行尾之间来回跳。
 3. 按 Ctrl-d 往下翻，翻到尽头再按 Ctrl-u 翻回来。

 Note: 数字加在 $ 前面是「先往下走 N-1 行，再到行尾」，3$ 就
       是先按 2j 再按 $；行内最后一个非空白字符用 g_。

 i        在光标这个字符的前面进入插入模式
 a        在光标这个字符的后面进入插入模式（a 是 append）
 Esc      回到普通模式

 1. 把光标移到下面标有 '-->' 的行。
 2. 找一处缺字的地方，按 i，敲进缺的字。

=                         3.2  I A o O                          =
=================================================================

   I        在行首第一个非空白字符前进入插入模式
   A        在行尾进入插入模式
   o        在下面新开一行，并进入插入模式
   O        在上面新开一行，并进入插入模式

 1. 把光标移到下面标有 '-->' 的行，任意位置。
 2. 按 A，光标会自己跳到行尾，敲上 Vim，和下面第二行对上。
 3. 按 O，在上面开一行输入注释；按 o，在下面开一行。

 --> The best text editor is
     The best text editor is Vim

=                      3.3  c s 和组合技巧                      =
=================================================================

   c{动作}    先按 {动作} 选中，再删掉并进入插入模式
   s          删掉光标下这个字符，直接进入插入模式
   C          从光标删到行尾并进入插入模式

 c 是「改变」，它等于「先做 {动作}，再按 i」。

 1. 把光标移到下面标有 '-->' 的行的句号上。
 2. 按 s，句号消失并进入插入模式，敲一个问号。
 3. 按 Esc。试着把光标移到某个词上，按 cw 改掉整个词。

 --> Vim is fun.
     Vim is fun?

=                       4.1  删除 x dd dw                       =
=================================================================

   x        删掉光标下的字符
   X        删掉光标前面的字符
   dd       删掉整行
   dw       删到下一个词的开头
   d$ / D   从光标删到行尾

 1. 把光标移到下面标有 '-->' 的行。
 2. 移动到每个多余的字符上，按 x 删掉它。

 --> Thhiss senttencee haass exxtra charracterss.

=================================================================
=                    4.2  复制与粘贴 yy p P                     =
=================================================================

   yy       复制（yank）整行
   yiw      复制光标所在的词
   yaw      复制光标所在的词，连它后面的空格一起
   p        粘贴到光标后面
   P        粘贴到光标前面

 1. 把光标移到下面标有 '-->' 的行，停在 apple 上，按 yiw。
 2. 把光标移到 pear 的 p 上，按 P：apple 被粘了过来，和 pear
    粘在了一起。
 3. 按 u 退回原样，把光标移回 apple，按 yaw 再复制一次，还
    是贴到 pear 前面，这回中间多了一个空格。

 --> apple banana pear
     apple banana apple pear

=================================================================
=                        4.3  撤销与重做                        =
=================================================================

   u        撤销上一步
   Ctrl-r   重做
   U        撤销对这一行的所有改动

 1. 把光标移到下面标有 '-->' 的行，按 x 删掉几个字符。
 2. 按 u 一步一步把它们全找回来。
 3. 按 Ctrl-r 重做，再按 u 撤销，来回几次找手感。

 --> Undo is the best feature of Vim.

 Note: 括号、换行、粘贴这类成组的改动也算一步，u 一次全撤。

=================================================================
=                        4.4  保存与退出                        =
=================================================================

 :w           保存
 :w 文件名     另存为另一个名字
 :wq / :x     保存并退出
 :q           关闭当前窗口
 :q!          强制关闭，未保存的改动全部丢掉

 1. 随便打几个字，文件立刻变成「已修改」。
 2. 输入 :w 回车，提示消失，改动写回磁盘。
 3. 再改一点，输入 :q，Vim 会拒绝退出并提醒你。
 4. 这次输入 :wq，改动保存，Vim 关闭这个窗口。

 Note: :q 遇到未保存的改动会停下来，这是保护不是出错。

 * x / X 删光标下 / 前的字符，dd 删整行，dw 删到下个词。

 * yy / yiw 复制整行 / 一个词，p 和 P 粘在光标后 / 前；u 撤
   销，Ctrl-r 重做，U 撤销本行改动。

 * :w 保存，:wq 保存并退出，:q! 丢弃改动强制退出。

=================================================================
=                       5.1  找什么 / n N                       =
=================================================================

   /词     向下搜索
   ?词     向上搜索
   n        跳到下一个匹配
   N        跳到上一个匹配
   *        把光标下的词当搜索词，向下找
   #        把光标下的词当搜索词，向上找

 1. 输入 /banana 再回车，光标会跳到第一个 banana。
 2. 用 n 在所有 banana 之间来回跳，用 N 反着跳。
 3. 把光标放到一个单词上，按 * 直接开始找它。

 Note: 搜索可以直接用正则，比如 /^\s 找以空白开头的行。

=================================================================
=                       5.2  改成什么 :s                        =
=================================================================

   :s/旧/新/        当前行第一个
   :s/旧/新/g       当前行全部
   :s/旧/新/ic      当前行全部，忽略大小写
   :s/旧/新/gc      当前行全部，逐个问你 y/n
   :%s/旧/新/g      整个文件
   :%s/旧/新/gc     整个文件，逐个问你 y/n
   :%s/旧/新/gn     只数一数有几个，不真的改

 1. 把光标移到下面标有 '-->' 的行。
 2. 输入 :s/banana/orange/g 回车，整行的 banana 都换成
    orange，和下面第二行对上。
 3. 输入 :%s/orange/apple/gc 回车，挨个回答 y 或 n；改多了
    按 u 退回来。
 4. 输入 :%s/apple/mango/gn 回车，只数出有几处，一个字都不
    改。

 --> banana banana banana
     orange orange orange

 * / 向下找，? 向上找，n / N 下一个 / 上一个。

 * * / # 直接用光标下的词当搜索词。

=                        6.1  v V Ctrl-v                        =
=================================================================

   v        字符选择模式
   V        行选择模式
   Ctrl-v   块选择模式（方块）

 1. 把光标移到下面标有 '-->' 的行，按 v，一个字符被选中了。
 2. 用 l l l 把选区拉长，再按 V 换成整行，再按 Ctrl-v 换成

 --> try every selection mode on this line

=================================================================
=                      6.2  选区里能干什么                      =
=================================================================

   d    删掉选区
   c    删掉选区并进入插入模式
   y    复制选区
   p    在下面粘一份选区
   >    缩进
   <    反缩进
   :    在选区上执行一条命令
   I    在每一行选区开头进入插入模式
   A    在每一行选区末尾进入插入模式

 1. 把光标放到下面标有 '-->' 的行，按 V 选中它，再按两下 j
    把下面两行也圈进来。
 2. 按 > 缩进整块，注意松手后选区还在。
 3. 按 I，输入 - ，按 Esc：三行的开头都多了 - 。

 --> one two three
     four five six
     seven eight nine

 块选择配合 I / A / d，能一次改整齐一片表格：

 1. 把光标放到下面第一行的第一个字符上，按 Ctrl-v。
 2. 按两下 j 到第三行，再按三下 l 选到某一列。
 3. 按 I，输入 X，按 Esc：三行同一列的位置都被写上了 X。

 --> one two three
     one two three
     one two three

=                         7.1  词 iw aw                         =
=================================================================

   iw    词内，不含两侧空白
   aw    词外，含后面的空白

 i 和 a 的区别就是「内」和「外」：内不含外围，外含外围。

 1. 把光标移到下面标有 '-->' 的行，停在第一个 word 上。
 2. 按 diw，word 被删掉，双份空白留在原地（看第二行）。
 3. 按 u 退回，再按 daw，连后面那份空白也一起没了。

 --> This is a word and another word.
     This is a  and another word.

=================================================================
=                     7.2  成对的符号与组合                     =
=================================================================

   i" / a"    双引号内 / 外
   i' / a'    单引号内 / 外
   i( / a(    圆括号内 / 外
   i[ / a[    方括号内 / 外
   i{ / a{    花括号内 / 外
   i< / a<    尖括号内 / 外

 1. 把光标移到下面标有 '-->' 的行，停在 hello 上。
 2. 按 ci"，引号里的内容被清空，光标进入插入模式。
 3. 敲上 world，Esc，引号本身留了下来，和第二行对上。
 4. 按 u 退回原样，再按 va"，看选区正好圈住带引号的词。

 --> say("hello", "world")
     say("world", "world")

 文本对象前面还可以接 d、c、y，意思是删、改、复制：

 1. 把光标放进下面标有 '-->' 行的 (baz) 里，停在 b 和 a 之
    间。
 2. 按 di(，括号留着，baz 没了；按 u 退回，再按 da(，连括
    号一起消失，看第二行。
 3. 按 u 退回原样，把光标放到 bar 上，分别试 ci( 和 ya(，
    每次试完都按 u 退回来。

 --> call foo(bar(baz), 42)
     call foo(bar, 42)

=                        9.1  寄存器与宏                        =
=================================================================

 寄存器是 Vim 内部的小抽屉，名字就是一个字符。剪贴板和它
 完全是两回事：Vim 内部的复制默认不进系统剪贴板。

   "ayy     把整行复制进寄存器 a
   "ap     在光标后粘贴寄存器 a 的内容
   "aP     在光标前粘贴寄存器 a 的内容
   :reg    列出所有寄存器和它们的内容
   qa      开始录宏，录到寄存器 a
   q       停止录制
   @a      重放寄存器 a 里的宏
   @@ / 3@a   再放一次 / 连续放三次

 1. 输入 :reg，看看这些小抽屉里都装了些什么。
 2. 把光标移到下面标有 '-->' 的行，按 "ayy 存进 a，再按 "ap
    贴一份试试。
 3. 按 u 撤掉贴出来的那一行，把光标移回标有 '-->' 行的行首
    （按 0）。
 4. 按 qa 开始录制，依次按：w、cw、no、Esc、j。
 5. 按 q 停止录制，这时第一行已经变成 go no now。
 6. 把光标移到第二行，按 @a；再按 @@ 改第三行。

 --> go home now
     go home now
     go home now

 全部做完，三行都变成 go no now。

 Note: 录进去的那个 j 让光标每改完一行就往下挪一格，所以连
       着按 @a 就能一行一行改下去，录一次一直能用。

=================================================================
=                        第9章 章节回顾                         =
=================================================================

 * 寄存器和剪贴板是两回事，:reg 能看到全部内容。

 * "ayy 存进 a，"ap / "aP 从 a 贴出；qa 开始录，q 停止，
   @a 重放，@@ 重复，3@a 连放三次。

=                        10.1  配置文件                         =
=================================================================

 Vim 启动时会自动读家目录下的 .vimrc；在 Vim 里敲 :version
 能看到实际读的是哪条路径，通常就是 ~/.vimrc。

 1. 输入 :split $MYVIMRC，配置文件在上面一半打开。
 2. 敲上这几行：

      set number
      set expandtab
      set tabstop=4 shiftwidth=4
      set ignorecase smartcase

 3. 输入 :w 保存，再输入 :source $MYVIMRC 让它生效。
 4. 按 Ctrl-w j 回到下面的教程窗口，输入 :set number?，看看
    选项真的改了没。

   :set 选项?        看这个选项现在是什么值
   :set all          列出所有选项和它们的值
   :source 文件      重新读一遍配置或脚本

=================================================================
=                        第10章 章节回顾                        =
=================================================================

 * 配置文件是家目录下的 .vimrc，用 :e $MYVIMRC 打开。

 * :source 重新加载，:set 选项? 查看，:set 选项& 复位。

 * 常用几项：number、expandtab、tabstop/shiftwidth、
   ignorecase、smartcase。
