=================================================================
=                             导读                              =
=================================================================

 这份教程讲 Vimore 在原版 Vim 之上加的东西：Leader 菜单、系
 统剪贴板、括号操作、终端、折叠、Git、格式化等等。原版 Vim
 怎么用不在这里讲，hjkl、i、dd、v、:%s/// 这些基础请先在
 vim.tutor.txt 里过一遍(最好用 vim --clean vim.tutor.txt 打
 开基础教程，因为 Vimore 修改了一些原版的操作)。

=================================================================
=                    1.1  Leader 就是空格键                     =
=================================================================

 按下 <Space> 一次(只按一下就松开)，屏幕右下角会弹出一个小
 菜单，列出目前所有可用的键。

 1. 把光标放到任意一行上，按一下空格，菜单会停在屏幕上。
 2. 按 Esc 关掉它。

 菜单长这样，叶子在上，子菜单在下，中间空一行：

 /      注释/取消注释
 P      从系统剪切板粘贴(前)
 Q      全部退出
 W      全部保存
 f      格式化代码
 p      从系统剪切板粘贴
 q      退出
 r      查看寄存器
 y      复制到系统剪切板

 b      <括号>
 c      <维护>
 g      <Git>
 h      <显示>
 s      <整理>
 t      <窗口>
 w      <写入>
 z      <视图>

 Note: 带尖括号的是子菜单，进得去；其余的按下去就执行。按空
       格之后有 300 毫秒判断你是接着按 y / p / P 还是要开菜
       单。菜单开起来后按 Esc / 不存在的子项会关掉，闲置约
       3 秒也会自动关（g:vimore_menu_timeout 可改）。

=================================================================
=                       1.2  子菜单与退出                       =
=================================================================

 在菜单里再按一个键，就能进子菜单或者执行命令。

 1. 按空格调出菜单，按 b，标题变成 Leader b - 括号，再按 d
    进到第三层，标题是「删除指定括号对及其内容」。
 2. 按 Esc，整个菜单一次全关(Esc 不是退一层)。

 第二层(按 b 之后)长这样，两个都是子菜单：

 a      <在可视选区外添加指定括号>
 d      <删除指定括号对及其内容>

 再按 d，第三层列出五种括号(键 + 用途)：

 " 双引号   ' 单引号   ( 圆括号   [ 方括号   { 花括号

 Note: 标题里写着当前路径，看到 Leader b 就知道自己进了一层。
       按到菜单里没有的键，菜单也会直接关掉。

=================================================================
=                        第1章 章节回顾                         =
=================================================================

 * 单独按一下空格，屏幕右下角弹出 which-key 风格的菜单。
 * 带 <名字> 的是子菜单，标题里显示当前路径。
 * Esc 或按菜单里没有的键，整个菜单直接关掉；顶层按 q 执
   行退出。
 * SPC y / p / P 有更长的映射，会直接执行，菜单不出现。

=================================================================
=                      2.1  保存退出与查看                      =
=================================================================

   SPC w     保存当前文件
   SPC w s   清理整个文件的行尾空格
   SPC w c   光标位置的信息(行、字、字节)
   SPC W     保存所有窗口里的文件
   SPC Q     退出所有窗口
   C-s       保存(普通模式和插入模式都认)
   SPC h h   关掉搜索高亮
   SPC h x   用十六进制方式看当前文件
   SPC h X   退出十六进制显示

 1. 随便改几行，按空格调出菜单，按 w 进「写入」，再按 w 保
   存；在插入模式里直接按 C-s 也一样能存，存完还留在插入
   模式，不会打断你继续打字。
 2. 输入 /菜单 回车找几个，按空格 h h，搜索高亮就没了。(记得
    回来)
 3. 按空格 h x 把文件变成十六进制看原始字节，改完按空格 h X
    换回来。

 Note: 存完会提示一下，2 秒后自动清掉。十六进制模式看的是文
       件原始字节，编辑器乱码或想看清不可见字符时很管用。

=================================================================
=                        第2章 章节回顾                         =
=================================================================

 * SPC w 保存，SPC w s 清行尾空格，SPC w c 看光标位置信息。
 * SPC W 全部保存，SPC Q 全部退出，C-s 在哪儿都能存。
 * SPC h h 取消搜索高亮，SPC h x / X 进 / 出十六进制。

=================================================================
=                        3.1  系统剪切板                        =
=================================================================

   SPC y     把当前行复制到系统剪贴板
   SPC p     在光标后粘系统剪贴板
   SPC P     在光标前粘系统剪贴板
   C-x       可视模式里把整个选区剪进系统剪贴板
  F2        普通/插入模式里开关粘贴模式

 1. 把光标移到下面标有 '-->' 的行，停在 banana 上。
 2. 按空格 y 就完事了，菜单不会出现，这一行已经在剪贴板里。
 3. 切到别的程序粘一下，粘的应该是这一行；回 Vim 按空格 p
    把它贴回来。

 --> I like banana and banana.

 再看 C-x，它是剪切(连删带拷)，不是单纯的复制：

 1. 把光标移到下面标有 '-->' 的 half 上，按 v，按三下 l 选
    中它，按 C-x：half 消失并进了剪贴板，这一行变成下面第
    二行的样子(中间留下两个空格)。

 --> whole half whole
     whole  whole

 Note: 原版 Vim 的 yy 只在内部复制；Vimore 特意关掉了剪贴板
       自动同步，所以 SPC y / p / P 才是真剪贴板。

=================================================================
=                        第3章 章节回顾                         =
=================================================================

 * SPC y 复制到系统剪贴板，SPC p / SPC P 粘回来。
 * 可视模式里 SPC y / p / P 作用于选区，C-x 把选区剪进剪贴
   板。
 * F2 在普通和插入模式都能开关粘贴模式，粘外部代码时很好用。

=================================================================
=                         4.1  快速注释                         =
=================================================================

 SPC / 在普通模式里注释 / 取消注释光标这一行；在可视模式里选
 中几行再按 SPC /，就对整块做同样的事。

 1. 把光标移到下面第一行，按空格 /，行前面多了注释符。
 2. 再按一次空格 /，符号没了。
 3. 按 V 选中下面三行，按空格 /，整块一起注释；再按一次还
    原。

 --> # python
     x = 1
     y = 2

 注释符是按文件类型自动挑的：

   #          python sh bash zsh yaml yml ruby perl
   --         lua sql
   //         c cpp java javascript typescript go rust
              csharp php json scss
   "          vim vimrc
   <!-- -->   html markdown
   /* */      css
   %          tex

 Note: 认不出来的文件类型就退回 #，也就是普通行注释。选区
       模式下只有每一行都注释了才整块去掉，否则整块加上，
       所以反复按一定还原。

=================================================================
=                        第4章 章节回顾                         =
=================================================================

 * SPC / 注释或取消注释当前行，可视模式选中几行再按同
   一个键。
 * 注释符按文件类型自动选，按一次加，按两次还原。
 * 支持 # -- // " <!-- --> /* */ % 这些风格。

=================================================================
=                    5.1  智能补全与智能退格                    =
=================================================================

 在插入模式里敲 ( [ " 会自动补全另一半；{ 默认也补，但在
 C / C++ / CSS 里不补。敲 ) ] } > 时如果光标正好停在对应
 的那一半上，会直接跳过它。

 1. 插入模式，输入 foo(，屏幕上自动变成 foo(|)。
 2. 输入 bar，这时按 )，光标会跳过右边那个现成的 )，不会多
    打一个；按退格则 () 一起消失。

 " 也一样：光标后已经有同款引号就直接跳过去；光标后紧跟别的
 字符就只打这一个；在空处则数前面的引号，偶数次自动补一对，
 奇数次只打这一个。

 1. 插入模式，输入 x = ""，光标自动停在两个引号中间。
 2. 直接按退格，"" 一起消失了。
 3. 再输入一遍 x = "hello"，把 hello 一个个删掉，光标停在空
    的 "" 中间按退格，效果一样。

 Note: 退格是成对的，空的 () [] {} "" 在中间按一次退格就整个
       消失。自动补左半边的是 ( [ " 和 {（C/C++/CSS 除外），
       < 只在 HTML / XML 里补全。

=================================================================
=                      5.2  删括号与加括号                      =
=================================================================

 SPC b d 之后选括号类型，就把光标所在的那一对括号连里面的东西
 一起删掉；SPC b a 是反过来，给选区外面套一对括号。

   SPC b d ( [ { " '    删掉光标所在的那对括号和内容
   SPC b a ( [ { " '    给可视选区外面套一对括号

 1. 把光标放进下面标有 '-->' 行的 (baz) 里，停在 b 和 a 之
    间，按空格 b d (，第二行是删完的样子。

 --> call foo(bar(baz), 42)
     call foo(bar, 42)

 2. 按 u 退回去，把光标放进 { key: val } 里，按空格 b d {：

 --> if ok { key: val }
     if ok

 3. 按 u 退回去，按 V 选中整行，按空格 b a (，整行被套上括
    号，第二行是加完的样子。

 --> print(sum(a, b))
     (print(sum(a, b)))

 Note: 选区跨行时，左括号加在第一行选中处，右括号加在最后
       一行选中处；SPC b a 只能在可视选区里用。

=================================================================
=                        第5章 章节回顾                         =
=================================================================

 * 插入模式里 ( [ " 自动配对(< 只在 HTML 里)，) ] } > 会
   自动跳过。
 * 退格是成对的，空的 () [] {} "" 一次退格全消失。
 * SPC b d ( [ { " ' 删括号和内容，SPC b a 给选区加括号。

=                        6.1  终端与运行                        =
=================================================================

   SPC t t   在底部开一个终端
   SPC t v   在右边开一个终端
   SPC t k   有终端就关掉，没有就重新开一个
   SPC t r   在最新的那个终端里跑当前文件
   F5        直接跑当前文件
   F6        调试当前文件

 1. 按空格 t t，屏幕下方三分之一变成终端，敲 ls 回车。
 2. 按 C-\ C-n 回到普通模式，再按空格 t k 把终端关掉。
 3. 新建一个 .py 文件写几行 print，按 SPC t r / F5 看输出。

   print("hello")
   print("vimor")

 Note: 终端里按 C-\ C-n 回普通模式，C-S-c 复制、C-S-v
       粘到系统剪贴板。C-S-h/j/k/l 切换窗口。

 Note: SPC t r / F5 都是先存盘，再在最新终端里跑当前文件。
       Python 走 python3，Go 走 go run，C/C++ 用 gcc/g++ 编
       译后运行，JS 走 node，Shell 走 bash，Lua 走 lua，Rust
       走 cargo run。F6 在终端里调试：Python 用 pdb，C/C++
       用 gdb，Go 用 dlv（调试当前目录的包，不是单个文件）。

=================================================================
=                        第6章 章节回顾                         =
=================================================================

 * SPC t t 开底部终端，SPC t v 开右侧终端，SPC t k 开 / 关。
 * 终端里 C-\ C-n 回普通模式，C-S-c / C-S-v 走系统剪贴板。
   C-S-h/j/k/l 切换窗口。
 * SPC t r 存盘后在最新终端里跑，F5 直接跑，F6 调试。

=================================================================
=                    7.1  文件浏览器与标签页                    =
=================================================================

   F3        在当前窗口开文件浏览器
   F4        垂直分屏开文件浏览器
   SPC t f   和 F3 一样
   SPC t F   和 F4 一样
   SPC t n   新建标签
   SPC t e   新标签打开当前文件
   SPC t c   关闭当前标签
   SPC t o / l   只留当前标签 / 列出所有标签
  SPC t u / d   新标签打开上一个文件 / 在新标签里打开所在目录
   SPC t M / N   标签左移 / 右移
   Alt 左  / 右  上一个 / 下一个标签页

 1. 按 F3，出现一个列表，目录树在前，文件在后。
 2. 把光标移到某个文件名上按回车，就在当前窗口打开了。
 3. 按 F4 试一次，浏览器和文件左右分屏；再按空格 t e，在
    新标签里打开当前文件。

 Note: 浏览器里的顺手键：回车打开，o 水平分屏开，v 垂直分屏
       开，t 新标签开，P 回到上个窗口，p 预览，i 换列表样
       式，Ctrl-l 刷新，% 是在当前目录新建文件；关掉浏览器
       用 :q。

 Note: 不带 Leader 的顺手记一下：C-h C-j C-k C-l 切窗口，
       C-t 保持 Vim 默认（弹出标签栈），Alt-左右切标签。
       C-w 是窗口命令前缀，C-w c 关窗口；新建标签用 SPC t n。

=================================================================
=                        第7章 章节回顾                         =
=================================================================

 * F3 / F4 开文件浏览器，SPC t f / F 同上。
 * SPC t n 新标签，SPC t e 新标签开当前文件，SPC t c 关。
 * SPC t u 在新标签打开上一个文件，o 只留当前，M / N 移标签。

=                           8.1  折叠                           =
=================================================================

   SPC z z   把所有能折的都折起来
   SPC z a   在光标这行折 / 展开切换
   SPC z Z   全部展开

 1. 打开一个缩进过的文件，比如下面这段。
 2. 把光标放在第二行按空格 z z，整段折成一行；再按空格 z a

   SPC s u   排序并去掉重复

   SPC s d   删掉所有空行

 1. 用 V 选中下面四行，按空格 s，字母排好了。

=                    11.1  配置维护与格式化                     =
=================================================================

   SPC c e   打开 Vimore 的配置文件
   SPC c v   重新加载 Vimore 的配置
   SPC c c   跑一次代码检查，和 F8 一样
   SPC f     自动格式化当前文件
   F9        基础格式化，就是 gg=G
   F10       自动格式化，和 SPC f 一样
   F7        切换自动换行，并报一下当前 wrap

   :VimoreMenu   直接打开 Leader 菜单
   :VimoreTutor  重新打开这份教程
   :VimMaze      仓库根目录的迷宫小游戏（? 帮助，q 退出）

 1. 按空格 c e 打开配置，在顶部把 g:author 和 g:email 改成
    你自己的，保存。
 2. 回别的窗口按空格 c v，改动立刻生效。
 3. 把下面这段缩进打乱的代码敲进新文件，按 F9 排好。

   def f(a,b):
   x=a+b
       return x

   def f(a, b):
       x = a + b
       return x

 Note: SPC f / F10 在后台跑格式化工具，不卡住编辑器，跑完
       自动重新读文件并还原光标。Python 用 black / ruff /
       autopep8，Go 用 gofmt，JS / TS 用 prettier，C / C++
       用 clang-format，Lua 用 stylua，都没有就退回 F9。

 Note: 想改行为，可在 source 之前设置 g:vimore_autochdir=1
       打开自动切目录，g:vimore_strip_whitespace=0 关闭保存清空格，
       g:vimore_menu_timeout 改菜单自动关闭的毫秒数。

 Note: SPC c c / F8 也在后台跑，发现的问题会放进 quickfix
       并自动打开；支持 Python、JS/TS、Go、Rust、Lua、Shell、
       C/C++、JSON、YAML 等。保存时行尾空格会被自动清掉，
       Markdown 例外，因为行尾两个空格在 Markdown 里是换行。

=                        第11章 章节回顾                        =
=================================================================

 * SPC c e 打开配置，改完 SPC c v 重新加载，记得先改顶部
   的 g:author 和 g:email，新建文件的头会用。
 * SPC f / F10 自动格式化，F9 基础缩进，SPC c c / F8 检查。
 * SPC w s 清行尾空格，保存时会自动清，Markdown 除外。

=================================================================
=                     12.1  缩进与缩进宽度                      =
=================================================================

 在普通模式里，< 和 > 单独按一下就能把当前行缩进一级，不
 用带上数字；可视模式里选中几行再按，就一起缩进。

 1. 把光标移到下面第三行(缩进多的 done())，按 <，它和第
    二行对齐了。
 2. 按 u 退回原样，再按 > 缩进一级，来回试几次。

 --> if ok
     run()
         done()

 缩进宽度是按文件类型定的：

   4 格    python sh go c cpp java rust

=                    13.1  行号状态栏和光标                     =
=================================================================

 普通模式显示相对行号，插入模式显示绝对行号，切换是自动
 的，你什么都不用按。

 1. 把光标停在下面第 3 行，看左边那列的数字。
 2. 按 i 进插入模式，数字立刻变成真的行号；Esc 出去又变

   (1) 第一行显示 1
   (2) 光标在第二行，这里是 2
   (3) 下面那行显示 1

 状态栏被换成了这样，左边是模式，右边一堆信息：

   [-] Vimore.vimrc  [vim] [unix] [utf-8] [128,9] [42%] 21:30

 左边那个方括号是模式指示器，每种模式一个颜色：

   [-] 普通   [I] 插入   [v] 可视   [V] 行可视

 没保存时文件名后面跟一个 +。标签栏也是定制的，名字太长会
 截短成一个 …，当前标签高亮。

 Note: 光标也跟着模式换：插入是闪烁竖线，普通是方块，可视
       是不闪的方块。行尾空格会变成灰色一小段，第 120 列有
       一条淡竖线提醒你该换行了。

=                      16.1  寄存器与剪贴板进阶                  =
=================================================================

 Vim 的复制粘贴走「寄存器」，不只是系统剪贴板：

    ""        无名寄存器，普通 y / d / p 默认用它
    "0        最近一次 yank，不会被 d / x 覆盖
    "1~"9     最近九次删除
    "+        系统剪贴板（X11 / Wayland 桥接）
    "*        X11 的主选区
    "a~"z     26 个命名寄存器，可长期存放

  1. 在一行上按 yy，接着删掉另一行，再按 "0p：贴回来的是刚才
     y 的那行，不是删掉的那行。
  2. 选中一段按 "ay 存进 a 寄存器，去别处按 "ap 贴出来。
  3. 输入 :reg 查看所有寄存器里都装了什么。

 Vimore 另外把系统剪贴板做成了顺手键：

    SPC y     当前行 / 选区复制到系统剪贴板
    SPC p/P   从系统剪贴板粘到光标后 / 前
    C-x       可视模式剪切到系统剪贴板

 Note: 在 Wayland 下，注册了 wl-copy / wl-paste 时会自动桥接；
       没有这两个命令时仍可用 "+y / "+p 走 X11 剪贴板。

=                       第16章 章节回顾                          =
=================================================================

 * "0 存最近 yank，"a~"z 是命名寄存器，:reg 查看全部。
 * Vimore 的 SPC y / p / P 和 C-x 走系统剪贴板。
 * paste 模式用 F2 切，普通/插入模式都能切。

=                        17.1  宏：录一遍，自动重复               =
=================================================================

 宏就是把一串按键录进寄存器，之后一键重放。

    q<字母>   开始录制到某个寄存器，比如 qa
    q         停止录制
    @a        重放 a 寄存器里的宏
    @@        重放上一次用过的宏
    20@a      连续重放 20 次
    qA        向 a 寄存器末尾追加录制

  1. 把光标放到下面第一行。
  2. 依次按：qa  I- <Esc>  j  q   —— 录一个「行首加 - 并下移一行」的宏。
  3. 按 @a，第二行也加上了 -；再按 @@，第三行也加上了。
  4. 按 5@a 可以一口气处理后面五行。

  --> apple
      banana
      cherry
      date
      elderberry

 Note: 录宏时尽量用 j / k / 0 / $ / w 这类相对移动，别用绝对
       行号，这样宏才能重复用在别处。录错了用 :let @a=' 清空。

=                       第17章 章节回顾                          =
=================================================================

 * qa 录制、q 结束、@a 重放、@@ 重复上一次、N@a 批量重放。
 * qA 追加录制；宏存在寄存器里，:reg 能看到。

=                       20.1  标签页进阶                         =

 标签页是一组窗口的容器，不是「一个文件一个标签」那么死板。

    :tabnew       新建空标签        :tabedit 文件   新标签打开文件

  3. 输入 :tabs 看列表，最后按 SPC t o 只留当前。

 Note: SPC t u 不是「恢复刚关的标签」，Vim 没有可靠的内建接口；

    :messages      看最近的消息和报错
    :set 选项?     查看选项当前值
    :set 选项&     把选项恢复默认值
    :highlight     查看当前高亮组
    :echo g:colors_name  查看主题名（真正颜色在 vimrc 第 3 节，无 colors/ 目录）

 Vimore 提供的三个开关（在 source 之前设置）：

    g:vimore_autochdir        1 = 进文件时自动 cd（默认 0）
    g:vimore_strip_whitespace 0 = 保存时不清行尾空格（默认 1）
    g:vimore_menu_timeout     菜单自动关闭毫秒数（默认 3000）

  1. 输入 :verbose map <F10>，看看它在 Vimore.vimrc 哪一行定义。
  2. 输入 :messages，确认启动时没有报错。
  3. 输入 :VimoreMenu 打开菜单，:VimMaze 打开迷宫小游戏（? 帮助）。

 Note: 改完配置不用重启，按 SPC c v 重新 source 即可；autocmd
       都收在 augroup 里，重复加载不会越堆越多。

 教程到这里就结束了。你已经知道：

 * 空格是 Leader，单独按一下弹菜单，Esc 或按错键就关掉，顶层
   q 退出。
 * SPC w / W / Q 管保存退出，C-s 在哪儿都能存；SPC y / p /
   P 走系统剪贴板，普通 yy 只在 Vim 内部。
 * SPC / 快速注释，注释符按文件类型自动挑。
 * SPC b d 删括号和内容，SPC b a 给选区加括号；插入模式自
   动补全括号引号，退格成对删除。
 * SPC t t / v / k / r 管终端，F5 跑、F6 调试，F3 / F4 浏览。
 * SPC z 折叠，SPC s 排序，SPC g 是 Git，SPC c 管配置。
 * < 和 > 保持 Vim 默认（单按缩进当前行），行号、状态栏、
   光标形状都跟着模式变。
 * 寄存器、宏、缓冲区、窗口、标签页、文本对象和正则都是 Vim
   的原生能力，菜单只是把它们串起来。
