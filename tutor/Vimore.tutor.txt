=================================================================
====================导                     读====================
=================================================================

  这份教程讲 Vimore 在原版 Vim 之上加的东西：Leader 菜单、系
  统剪贴板、括号操作、终端、折叠、Git、格式化等等。原版 Vim
  怎么用不在这里讲，hjkl、i、dd、v、:%s/// 这些基础请先在
  vim.tutor.txt 里过一遍。

=================================================================
===================1.1  Leader 就 是 空 格 键====================
=================================================================

  按下 <Space> 一次（只按一下就松开），屏幕右下角会弹出一个小
  菜单，列出目前所有可用的键。

  1. 把光标放到下面标有 '-->' 的行，什么都不做；按一下空
     格，菜单会停在屏幕上。
  2. 按 Esc 关掉它。

  菜单长这样，叶子在上，子菜单在下，中间空一行：

     /     注释/取消注释
     Q     全部退出
     W     全部保存
     f     格式化代码
     p     从系统剪切板粘贴
     q     退出
     r     查看寄存器
     y     复制到系统剪切板

     b     <括号>
     c     <维护>
     g     <Git>
     h     <显示>
     s     <整理>
     t     <窗口>
     w     <写入>
     z     <视图>

  Note: 带尖括号的是子菜单，进得去；其余的按下去就执行。整
        个菜单等键只有 300 毫秒，手快点就行。

=================================================================
=====================1.2  子 菜 单 与 退 出======================
=================================================================

  在菜单里再按一个键，就能进子菜单或者执行命令。

  1. 按空格调出菜单，按 b，标题变成 Leader b - 括号，再按 d
     进到第三层，标题是「删除指定括号对及其内容」。
  2. 按 Esc 退一层，再按 q 把整个菜单关掉。

     d     <删除指定括号对及其内容>
     a     <在可视选区外添加指定括号>

     (     圆括号      [     方括号
     {     花括号      "     双引号
                       '     单引号

  Note: 标题里写着当前路径，看到 Leader b 就知道自己进了一层。
        顶层按 q 会执行退出，子菜单里没有 q 这个键，按它就当
        取消菜单。

=================================================================
==========================1.3  键 位 表==========================
=================================================================

    SPC y / p / P     系统剪切板（直接执行，不弹菜单）
    SPC /             注释 / 取消注释
    SPC w  写         w 保存  s 清行尾空格  c 光标信息
    SPC q  退出       SPC W 全部保存  SPC Q 全部退出
    SPC h  显示       h 取消高亮  x 十六进制  X 退出十六进制
    SPC z  视图       z 全折叠  a 切换  Z 全展开
    SPC s  整理       s 排序  u 去重  n 数字序  d 删空行
    SPC g  Git        s 状态  d 差异  l 日志
    SPC g  Git        a 添加  c 提交  p 推送  P 拉取
    SPC t  窗口       t 底终端  v 右终端  r 运行  k 开 / 关
    SPC t  标签       n 新建  e 开当前  c 关闭  u 找回  l 列出
    SPC t  浏览       f 文件浏览器  F 竖版  M / N 移标签
    SPC b  括号       d 删括号内容  a 给选区加括号
    SPC c  维护       c 代码检查  v 重载配置  e 编辑配置
    SPC f  格式化     SPC r  查看寄存器

=========================CHAPTER 1 RECAP=========================
=================================================================

  * 单独按一下空格，屏幕右下角弹出 which-key 风格的菜单。
  * 带 <名字> 的是子菜单，Esc 退一层，标题显示当前路径。

====================2.1  保 存 退 出 与 查 看====================
=================================================================

    SPC w     保存当前文件
    SPC w s   清理整个文件的行尾空格
    SPC w c   光标位置的信息（行、字、字节）
    SPC W     保存所有窗口里的文件
    SPC Q     退出所有窗口
    C-s       保存（普通模式和插入模式都认）
    SPC h h   关掉搜索高亮
    SPC h x   用十六进制方式看当前文件
    SPC h X   退出十六进制显示

  1. 随便改几行，按空格 w w，菜单里「保存」亮着，按 w 走完；
     在插入模式里直接按 C-s 也一样能存，还会自动回普通模式。
  3. 输入 /TODO 回车找几个，按空格 h h，高亮消失；按空格
     h x 变十六进制，改完按空格 h X 变回来。

  Note: 存完会提示一下，两秒后自动清掉，屏幕保持干净。十六
        进制模式看的是文件原始字节，编辑器乱码或者想看清不
        可见字符时很管用。

=================================================================
=========================CHAPTER 2 RECAP=========================
=================================================================

  * SPC w 保存，SPC w s 清行尾空格，SPC w c 看光标位置信息。
  * SPC W 全部保存，SPC Q 全部退出，C-s 在哪儿都能存。
  * SPC h h 取消搜索高亮，SPC h x / X 进 / 出十六进制。

=================================================================
=======================3.1  系 统 剪 切 板=======================
=================================================================

    SPC y     把当前行复制到系统剪贴板
    SPC p     在光标后粘系统剪贴板
    SPC P     在光标前粘系统剪贴板
    C-x       可视模式里把整个选区复制到剪贴板
    F2        插入模式里开关粘贴模式

  1. 把光标移到下面标有 '-->' 的行，停在 banana 上。
  2. 按空格 y 就完事了，菜单不会出现，这一行已在剪贴板里。
  3. 切到别的程序粘一下，粘的应该是 banana；回 Vim 按空格 p
     粘回来，再按 v 选中第二行的 half，按 C-x 复制。

  --> I like banana and banana.
     whole half whole

  Note: 原版 Vim 的 yy 只在内部复制；Vimore 特意关掉了剪贴板
        自动同步，所以 SPC y / p / P 才是真剪贴板。

=================================================================
=========================CHAPTER 3 RECAP=========================
=================================================================

  * SPC y 复制到系统剪贴板，SPC p / SPC P 粘回来。
  * 可视模式里这几个键作用于选区，C-x 一键全选复制。
  * F2 是插入模式的粘贴开关，粘外部代码时很好用。

=================================================================
========================4.1  快 速 注 释=========================
=================================================================

  SPC / 在普通模式里注释 / 取消注释光标这一行；按住 Shift 再
  按 /，则是对选中的几行做同样的事。

  1. 把光标移到下面第一行，按空格 /，行前面多了符号。
  2. 再按一次空格 /，符号没了；停到第三行，按住 Shift 再
     按空格 /，整块一起注释。

  --> # python
     x = 1
     y = 2

  注释符是按文件类型自动挑的：

    #          python sh bash zsh yaml yml ruby perl
    --         lua sql
    //         c cpp java javascript typescript go rust
               csharp php json scss
    "          vim vimrc
    <!-- -->   html markdown
    /* */      css
    %          tex

  Note: 认不出来的文件类型就退回 #，也就是普通行注释。选区
        模式下先看第一行是不是已经注释了，是就整块去掉，不
        是就整块加上，所以反复按一定还原。

=================================================================
=========================CHAPTER 4 RECAP=========================
=================================================================

  * SPC / 注释或取消注释当前行，Shift + SPC / 对选区做。
  * 注释符按文件类型自动选，按一次加，按两次还原。
  * 支持 # -- // " <!-- --> /* */ % 这些风格。

=================================================================
=================5.1  智 能 补 全 与 智 能 退 格=================
=================================================================

  在插入模式里敲 ( [ 会自动补上另一半，敲 ) ] } > 时如果光标
  正好停在对应的那一半上，会直接跳过它。

  1. 插入模式，输入 foo(，屏幕上自动变成 foo(|)。
  2. 输入 bar，再输入 ) 就把 ) 补上了；同一个 ( 再敲一次
     )，光标只是跳过本来就该在那里的 )。

  " 也会自动补一对，而且会数前面已经出现了几个引号，奇数次
  只补左边，偶数次才补一对。

  1. 插入模式，输入 x = ""，光标自动在中间，输入 hello。
  2. 把光标移到这对引号中间，按退格，"" 一起没了。

  Note: 退格是成对的，空的 () [] "" 都在中间按一次退格就整个
        消失。HTML 里 < 也会配成 <>，但 C / C++ / CSS 的 {
        故意不补。

=================================================================
====================5.2  删 括 号 与 加 括 号====================
=================================================================

  SPC b d 之后选括号类型，就把光标所在的那一对括号连里面的
  东西一起删掉；SPC b a 是反过来，给选区套一对括号。

    SPC b d ( [ { " '    删掉光标所在的那对括号和内容
    SPC b a ( [ { " '    给可视选区外面套一对括号

  1. 把光标放进下面第一行的 foo(bar(baz), 42) 里，按空格
     b d (，整个 (bar(baz), 42) 没了。
  2. 把光标放进下面第三行的 foo[bar] 里，按空格 b d [。
  3. 把光标放进第五行的 {key: val} 里按空格 b d {；按 v 选
     中第七行按空格 b a ( 就套上了括号。

  --> call foo(bar(baz), 42)
     call foo(), 42)
     call foo(bar(baz), 42)
     call foo(), 42)
     if ok { key: val }
     if ok { }
     print(sum(a, b))
     print((sum(a, b)))

  Note: 光标在括号外面就不知道该删哪一对，这时会提示「光标
        不在 ( 内」。选区跨行时左括号加在第一行头上，右括
        号加在最后一行尾巴上。

=================================================================
=========================CHAPTER 5 RECAP=========================
=================================================================

  * 插入模式里 ( [ " < 自动配对，) ] } > 会自动跳过。
  * 退格是成对的，空的 () [] {} "" 一次退格全消失。
  * SPC b d ( [ { " ' 删括号和内容，SPC b a 给选区加括号。

=================================================================
=======================6.1  终 端 与 运 行=======================
=================================================================

    SPC t t   在底部开一个终端
    SPC t v   在右边开一个终端
    SPC t k   有终端就关掉，没有就重新开一个
    SPC t r   在最新的那个终端里跑当前文件
    F5        直接跑当前文件
    F6        调试当前文件

  1. 按空格 t t，屏幕下方三分之一变成终端，敲 ls 回车。
  2. 按 Esc 回到普通模式，再按空格 t k 把终端关掉。
  3. 新建一个 .py 文件写几行 print，按 F5 看输出。

    print("hello")
    print("vimor")

  Note: 终端里按 Esc 或 C-c 回普通模式，C-S-c 复制、C-S-v
        粘到系统剪贴板。

  Note: SPC t r 先存盘再跑，没终端就现开一个，命令按类型选：
        Python 走 python3，Go 走 go run，C 是 gcc 编译再跑，
        JS 走 node，Shell 走 bash，Rust 走 cargo run。F5 直
        接在屏幕里跑，类型比它多 Java 和 HTML（firefox 打
        开）但没有 Rust；F6 调试走 pdb、gdb 或 dlv。

=================================================================
=========================CHAPTER 6 RECAP=========================
=================================================================

  * SPC t t 开底部终端，SPC t v 开右侧终端，SPC t k 开 / 关。
  * 终端里 Esc 回普通模式，C-S-c / C-S-v 走系统剪贴板。
  * SPC t r 存盘后在最新终端里跑，F5 直接跑，F6 调试。

=================7.1  文 件 浏 览 器 与 标 签 页=================
=================================================================

    F3        在当前窗口开文件浏览器
    F4        垂直分屏开文件浏览器
    SPC t f   和 F3 一样
    SPC t F   和 F4 一样
    SPC t n   新建标签
    SPC t e   新标签打开当前文件
    SPC t c   关闭当前标签
    SPC t o / l   只留当前标签 / 列出所有标签
    SPC t u / d   找回刚关的标签 / 在新标签里打开所在目录
    SPC t M / N   标签左移 / 右移

  1. 按 F3，出现一个列表，目录树在前，文件在后。
  2. 把光标移到某个文件名上按回车，就在当前窗口打开了。
  3. 按 F4 试一次，浏览器和文件左右分屏；再按空格 t e，在
     新标签里打开当前文件。

  Note: 目录名按 % 会在旁边窗口里打开，q 关掉当前那个。

  Note: 不带 Leader 的顺手记一下：C-h C-j C-k C-l 切窗口，
        C-t 新标签，Shift-左右切标签。C-w 在这里是关标签页，
        不是关窗口，别按错。

=================================================================
=========================CHAPTER 7 RECAP=========================
=================================================================

  * F3 / F4 开文件浏览器，SPC t f / F 同上。
  * SPC t n 新标签，SPC t e 新标签开当前文件，SPC t c 关。
  * SPC t u 找回，SPC t o 只留当前，M / N 移标签，l 列出。

===========================8.1  折 叠============================
=================================================================

    SPC z z   把所有能折的都折起来
    SPC z a   在光标这行折 / 展开切换
    SPC z Z   全部展开

  1. 打开一个缩进过的文件，比如下面这段。
  2. 把光标放在第二行按空格 z z，整段折成一行；再按空格 z a
     展开那一行，按空格 z Z 全部摊平。

    func main() {
        if ok {
            run()
        }
        done()
    }

  Note: 折叠按缩进算，文件得先有缩进；折起来那行末尾显示
        + 开头的内容 ... N lines。

  * 折叠按缩进判断，折起来那行会告诉你藏了几行。

=======================9.1  排 序 与 整 理=======================
=================================================================

    SPC s s   排序
    SPC s u   排序并去掉重复
    SPC s n   按数字大小排序
    SPC s d   删掉所有空行

  1. 选中下面三行里的字母，按空格 s，字母排好了。
  2. 再按空格 s u，重复的那行没了。
  3. 选中下面三个数字，按空格 s n，10 会跑到 9 后面。

  * 可视模式里 SPC s / su / sn 只作用于选区。

============================10.1  Git============================
=================================================================

    SPC g s   git status
    SPC g d   git diff
    SPC g l   git log --oneline --graph
    SPC g a   git add 当前文件
    SPC g c   git commit，会让你写一句说明
    SPC g p   git push

  2. 按空格 g d，看看你改了哪些行。
  3. 按空格 g a 暂存，按空格 g c 写说明提交；再按 g l 看提

  Note: 输出直接刷在屏幕上，看完按回车或 Esc 关掉那半屏。
        SPC g a 只暂存当前这一个文件，不是 git add .，提交

========================CHAPTER 10 RECAP=========================
=================================================================

  * SPC g s / d / l 分别是 status、diff、log。
  * SPC g a 暂存当前文件，SPC g c 提交，p 推送，P 拉取。

==================11.1  配 置 维 护 与 格 式 化==================
=================================================================

    SPC c e   打开 Vimore 的配置文件
    SPC c v   重新加载 Vimore 的配置
    SPC c c   跑一次代码检查，和 F8 一样
    SPC f     自动格式化当前文件
    F9        基础格式化，就是 gg=G
    F10       自动格式化，和 SPC f 一样
    F7        切换自动换行，并报一下当前 wrap

  1. 按空格 c e 打开配置，在顶部把 author 和 email 改成你
     自己的，保存。
  2. 回别的窗口按空格 c v，改动立刻生效。
  3. 把下面这段缩进打乱的代码敲进新文件，按 F9 排好。

    def f(a,b):
    x=a+b
        return x

    def f(a, b):
        x = a + b
        return x

  Note: SPC f 会先看系统里有没有对应的工具：Python 用 black
        或 autopep8，Go 用 gofmt，JS / TS 用 prettier 或
        eslint，C / C++ 用 clang-format，Java 用 astyle，都
        没有就退回 F9 那种基础缩进。

  Note: SPC c c 走的是 Python 的 pylint / flake8 和
        JavaScript 的 eslint，其他类型会直接告诉你不支持。
        保存时行尾空格会被自动清掉，Markdown 例外，因为行尾
        两个空格在 Markdown 里是换行的意思。

=================================================================
========================CHAPTER 11 RECAP=========================
=================================================================

  * SPC c e 打开配置，改完 SPC c v 重新加载，记得先改顶部
    的 author 和 email，新建文件的头会用。
  * SPC f / F10 自动格式化，F9 基础缩进，SPC c c / F8 检查。
  * SPC w s 清行尾空格，保存时会自动清，Markdown 除外。

===================12.1  缩 进 与 缩 进 宽 度====================
=================================================================

  在普通模式里，< 和 > 单独按一下就能把当前行缩进一级，不
  用带上数字；可视模式里选中几行再按，就一起缩进。

  1. 把光标移到下面第二行，按 <，它往左挪了一格。
  2. 按 >，又挪回来。

  --> if ok
     run()
        done()

  缩进宽度是按文件类型定的：

    4 格    python sh go c cpp java rust
    2 格    javascript typescript html css json yaml markdown

  1. 新建一个 .py 文件敲 4 个空格，再建一个 .js 的敲同样 4
     个空格，看它怎么排；用 :set shiftwidth? 随时确认。

=================================================================
========================CHAPTER 12 RECAP=========================
=================================================================

  * 普通模式单按 < / > 就缩进 / 反缩进当前行，不带数字。
  * 可视模式里选中几行再按，会一起缩进，还保持选中。
  * 宽度按文件类型：Python、Go、C 4 格，JS、HTML 2 格。

=================================================================
==================13.1  行 号 状 态 栏 和 光 标==================
=================================================================

  普通模式显示相对行号，插入模式显示绝对行号，切换是自动
  的，你什么都不用按。

  1. 把光标停在下面第 3 行，看左边那列的数字。
  2. 按 i 进插入模式，数字立刻变成真的行号；Esc 出去又变
     回相对的。

    (1) 第一行显示 1
    (2) 光标在第二行，这里是 2
    (3) 下面那行显示 1

  状态栏被换成了这样，左边是模式，右边一堆信息：

    [-] Vimore.vimrc  [vim] [unix] [utf-8] [128,9] [42%] 21:30

  左边那个方括号是模式指示器，每种模式一个颜色：

    [-] 普通   [I] 插入   [v] 可视   [V] 行可视
    [B] 块可视 [R] 替换   [C] 命令行 [T] 终端

  右边依次是文件类型、格式、编码、行列、百分比和时间；改过
  没保存时文件名后面跟一个 +。标签栏也是定制的，名字太长会
  截短成一个 …，当前标签高亮。

  Note: 光标也跟着模式换：插入是闪烁竖线，普通是方块，可视
        是不闪的方块。行尾空格会变成灰色一小段，第 120 列有
        一条淡竖线提醒你该换行了。

=================================================================
========================CHAPTER 13 RECAP=========================
=================================================================

  * 普通模式相对行号，插入模式绝对行号，自动切。
  * 状态栏左边是模式指示器，右边是类型、格式、编码、行列、
    百分比、时间。
  * 标签栏会截短过长的名字，光标形状跟着模式变。

=====================14.1  文 件 头 与 补 全=====================
=================================================================

  新建 .py .go .sh .c .cpp .java .js .ts .rs .lua 这几种文件
  时，Vimore 会自动帮你填好开头。

  1. 新建一个空的 hello.py，保存。
  2. 看看是不是已经有 shebang、编码行、作者、邮箱、日期和
     一个空的三引号块；再建个空的 hello.c 看有没有 include。

  输命令和文件名时也都有补全：

    Tab        在候选里往下选一个
    Shift-Tab  往上选一个
    Enter      选中当前这个候选
    Ctrl-n     不用 Tab 也能往下翻候选

  1. 输入 : 再敲 :sp，会看到一列候选，按 Tab 选到 :split。
  2. 输入一个文件名的前几个字母，Tab 补出完整路径。

  Note: 作者和邮箱取配置顶部的 author 和 email，第一次用记
        得先去 SPC c e 改掉。按 Tab 时如果光标后面还有东
        西，补全会盖掉它们，改命令中间的词时正好顺手。

  * 新建 py go sh c cpp java js ts rs lua 时自动填文件头。
  * 头部里的作者和邮箱来自配置顶部的 author / email。

  教程到这里就结束了。你已经知道：

  * 空格是 Leader，单独按一下弹菜单，Esc 退一层，顶层 q 退出。
  * SPC w / W / Q 管保存退出，C-s 在哪儿都能存；SPC y / p /
    P 走系统剪贴板，普通 yy 只在 Vim 内部。
  * SPC / 快速注释，注释符按文件类型自动挑。
  * SPC b d 删括号和内容，SPC b a 给选区加括号；插入模式自
    动补全括号引号，退格成对删除。
  * SPC t t / v / k / r 管终端，F5 跑、F6 调试，F3 / F4 浏览。
  * SPC z 折叠，SPC s 排序，SPC g 是 Git，SPC c 管配置。
  * < 和 > 单按就缩进，行号、状态栏、光标形状都跟着模式变。

  打开一份真的文件从头用一遍，哪里卡住就回来查这一章。
  Vimore 的规矩就一句话：Less is more。用 :q! 退出这份教程。
