                     欢迎来到 Vim 交互式教程！
       这份教程讲的是原版 Vim，不依赖任何配置。用下面的命令
       打开它，确保环境是干净的：

          vim --clean vim.tutor.txt

       --clean 不加载任何 vimrc 和插件，看到的就是原版 Vim 的
       默认行为。本教程由 NeoVimore 项目编写，随项目以
       GPL-3.0 许可发布。

       一直按 j 往下读，读到文件最后一句，就算通关了。

=================================================================
=                        1.1  启动与退出                        =
=================================================================

 Vim 是模式化编辑器：普通模式发命令，插入模式写字。

    vim 文件          启动并打开文件
    vim --clean 文件   不加载任何 vimrc/插件，干净环境 (本教程推荐)
    :q                 退出 (有改动时会被拦住)
    :q!                强制退出，丢弃改动
    :w                 保存
    :wq / :x / ZZ      保存并退出

  1. 用 vim --clean tutor/vim.tutor.txt 打开本教程。
  2. 输入 :set number? 看行号选项；输入 :q! 再重新打开。
  3. 试着改一个字，再分别用 :q 和 :q! 体会区别。

 Note: --clean 下 $MYVIMRC 是空的，练配置时用临时文件，
       不要动你真正的 ~/.vimrc。

=                       2.1  h j k l 移动                       =
=================================================================

    h   左        j   下
    k   上        l   右

        ^
        j
    < h     l >
          k
          v

  1. 把光标停在本行，按 j 往下走三行，再按 k 回来。
  2. 按 h 走到行首，按 l 走到行尾。
  3. 可以加数字：10j 往下十行，5l 往右五个字符。

 Note: 方向键也能动，但 hjkl 双手不用离开主键盘，更快。

=================================================================

    b      上一个词开头

  3. 把光标放在一个词上按 e，看停在哪个字符。

=                      4.1  行内定位与翻屏                      =
=================================================================

    0                行首 (第 1 列)
    ^                行首第一个非空白字符
    $                行尾
    fx / Fx          行内找下一个 / 上一个字符 x
    tx / Tx          跳到 x 前面 / 后面
    ; ,              重复 / 反向重复上次 f t 查找
    gg / G           文件首 / 文件尾
    50G              跳到第 50 行
    Ctrl-d / Ctrl-u  向下 / 向上翻半屏
    Ctrl-f / Ctrl-b  向下 / 向上翻一屏
    zz               把当前行放到屏幕中间

  1. 把光标移到任意一行，按 0、^、$ 体会三种行位置。
  2. 按 f 加一个字母，看跳到哪里；按 ; 再跳一次。
  3. 按 Ctrl-d 往下翻，翻到尽头再按 Ctrl-u 翻回来。(这里是118行)
  4. 按 119G (G 是大写) 或命令 :119 到这一行。

 --> 这一行用来练习行内定位

 Note: $ 前加数字是「先往下 N-1 行再到行尾」，3$ 等价于先 2j 再 $。

=                       5.1  进入插入模式                       =
=================================================================

    i    在光标前插入
    a    在光标后插入
    I    在本行第一个非空白字符前插入
    A    在本行行尾插入
    o    在下面新开一行插入
    O    在上面新开一行插入
    Esc  回到普通模式

  1. 在普通模式按 i，输入几个字，按 Esc 回来。
  2. 按 A 在行尾追加文字，再按 Esc。
  3. 按 o 新开一行写一行字，按 O 在上方再开一行。

 Note: 插入模式里 Ctrl-h 删前一个字符，Ctrl-w 删前一个词，
       Ctrl-u 删到行首。这些是标准键，不会和菜单冲突。

=================================================================
=                     11.1  正则表达式入门                      =
=================================================================

 正则按四层学，别一次记完。

 1. 单个字符
    .         任意一个字符
    [abc]     字符集合：a 或 b 或 c
    [^abc]    排除集合
    \d        数字 [0-9]
    \w        字母或数字
    \s        空白

 2. 重复次数
    *         0 次或多次
    \+        1 次或多次
    \?        0 次或 1 次
    \{2,4}    2 到 4 次

 3. 位置与边界
    ^         行首
    $         行尾
    \< \>     单词边界

 4. 分组与选择
    \(...\)   分组
    \|        或者
    \v        very magic，括号 + | 不用反斜杠
    \c / \C   忽略 / 区分大小写

  1. 输入 /foo 再输入 /bar，分别看高亮。
  2. 输入 /\v(foo|bar)，同时高亮两者。
  3. 输入 /^\s*\d\+，找行首空白后跟数字的行。

 --> foo one
     bar two
     123 numbers

 Note: 先学正则，再学下一章的 :s 和 :g，会顺很多。

=                     12.1  替换与全局命令                      =
=================================================================

    :%s/旧/新/g      全文替换每行所有匹配
    :%s/旧/新/gc     逐个确认 y/n/a/q
    :s/旧/新/        当前行

    :g/模式/命令     对匹配的行执行命令

  1. 输入 :%s/banana/apple/g 替换下面所有 banana。

  3. 输入 :v/^#/d 只保留注释行。

 --> banana and banana

     another banana

 Note: 替换里的 & 表示刚匹配到的内容；:%s/banana/&&/g 会变成
       bananabanana。模式用的就是上一章的正则。

=                   23.1  Quickfix 与错误列表                   =
=================================================================

    :copen / :cclose       打开 / 关闭 quickfix
    :cnext / :cprev        下 / 上一个问题
    :cc 3                  跳到第 3 条
    :cfile 文件            读取错误文件
    :vimgrep /pat/ **/*.c  搜索并填充
    :grep -rn pat .        外部 grep 填充
    :make                  运行 makeprg
    :lopen                 位置列表 (窗口私有)
    [q / ]q                上 / 下一个 quickfix 项

  1. 输入 :vimgrep /printf/ **/*.c 再 :copen。
  2. 按 <CR> 跳源码，:cnext 继续。
  3. 输入 :make 看错误如何入列。

 Note: 配置里的 F8 检查工具会把结果放进 quickfix 并自动打开。

=================================================================
=                   24.1  表达式寄存器与计算                    =
=================================================================

    <C-r>=表达式<CR>   插入模式下算值并插入
    "=                 表达式寄存器 (只读)
    <C-r>"             插入上次删除/复制的内容
    <C-r>%             插入当前文件名
    <C-r>/             插入上次搜索词
    :echo 表达式       命令行计算

  1. 插入模式按 <C-r>=6*7<CR>，插入 42。
  2. 按 <C-r>=strftime("%Y-%m-%d")<CR> 插入日期。
  3. 输入 :echo 6*7 看结果。

 Note: "_ 是黑洞寄存器；"+ 是系统剪贴板；:reg 查看全部。

=                  25.1  标记、跳转与改动列表                   =
=================================================================

    m[a-z]       设置局部标记
    m[A-Z]       设置全局标记 (跨文件)
    'a / `a      跳到 a 标记行首 / 精确列
    ''           跳回上次位置
    <C-o>/<C-i>  跳转历史后退 / 前进
    g; / g,      改动位置后退 / 前进
    :marks       列出标记
    :jumps       列出跳转
    :changes     列出改动

  1. 在第 3 行按 ma，走远，按 'a 跳回。
  2. 按 <C-o> / <C-i> 在历史里前后走。
  3. 改几行后按 g; / g, 在改动间跳。

 Note: ' 是行首，` 是精确列，别混用。

=                      27.1  比较文件 diff                      =
=================================================================

    :diffsplit 文件    横向 diff
    :vertical diffsplit 文件  纵向 diff
    :diffthis / :diffoff   加入 / 退出 diff
    ]c / [c           下一个 / 上一个差异
    dp / do           推送 / 拉取当前块改动
    :diffupdate       重新计算

  1. 复制一份文件改几行，:diffsplit 副本。
  2. 用 ]c 跳差异，按 do 把对方内容拉过来。
  3. :diffoff 退出。

 Note: Git 的 diff 底层也是这个模式。

=                        31.1  综合练习                         =
=================================================================

 把前面能力串起来：

 1. 新建 note.txt，写几段英文，故意拼错几个词。
 2. :set spell，]s 找错词，z= 看建议，zg 收进词典。
 3. :set textwidth=60，gqap 重排段落。
 4. V 选几行，:'<,'>s/foo/bar/gc 逐个确认。
 5. :g/^TODO/d 删掉 TODO 行 (:g 再次登场) 。
 6. ma 存标记，走远，'a 跳回；g; 在改动间跳。
 7. :vimgrep /note/ **/*.txt，:copen，<CR> 跳源码。
 8. :mksession ~/note.session，:qall，vim -S 恢复。
 9. :diffsplit 副本，do 把改动拉回来。

 Note: 卡住时 SPC c k 看快捷键，:messages 看报错。
